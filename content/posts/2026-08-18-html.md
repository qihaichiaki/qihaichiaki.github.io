## 什么是HTML?  
* html是超文本标记语言  
	* 超文本: 文本、声音、图片、视频、表格、链接(**超文本：是一种组织信息的方式，通过超链接将不同空间的文字、图片、等各种信息组织在一起，能从当前阅读的内容，跳转到超链接所指向的内容**)  
	* 标记：由许多标签组成 
* html页面是运行到浏览器上面的(BS、CS)

## HTML文件基本结构  
```html
<html>
	<head>
		<title>Myhtml<title>
	</head>
	<body>
		hello world
	</body>
</html>
```

* 标签是元素。  
* 双标签: 标签有开始有结束``<html></html>``  
* 单标签只有一个开始。它可以有个优雅的方式结束：``<input/>``   
* **html** html文件根标签  
* **head** 编写页面的相关属性  
* **title** 页面标题  
* **body** 页面内容展示信息  
> 组成了一格DOM树  
> 所有的标签都是html子标签  
> head和body是兄弟标签  
> head和title父子标签  
> 每个标签都相当于一个对象，程序员拿到这些标签就可以拿到对象，然后对其进行增删查改  


## HTML的常见元素  
* **标签的默认效果不重要，语义很重要**  
### 页签标签  
```html
	<title>这是我的网页</title>
```

* 注意需要写在head标签中  

### 注释标签  
```html
	<!-- 我只是一个简单的注释 -->
```

* html渲染到浏览器上不会显示（源代码上依然可见）  
* ctrl /可以进行快速注释和取消注释  

### 文档声明  
* 不算是标签，算是一个特殊的标记  
* 如果不写声明，浏览器会以最新的标准渲染此网页(大多数)  
* 语法：  
```html
<!DOCTYPE html>
```

* doc文档，type类型。html表示H5(html5)进行渲染  
* 文档声明必须要放在源文件的第一行  

### 字符编码  
* 设定浏览器以什么方式进行解码  
* 语法（写在head中-默认以utf-8进行解码的）  
```html
<meta charset="UTF-8" />
```

### 设置语言  
* 为了让网页出现翻译提示（高端的浏览器可以会自动分析（但是特殊的场景下不行-比如混合语言））  
* 语法（为html标签的属性）  
```html
<html lang="">
</html>
```

* lang规则指示语言，通常存在：
1. zh-CN 中国大陆-简体语言  
2. zh-TW 中国台湾-繁体语言  
3. en-US 英语-美国  
4. en-GB 英语-英国  
5. zh 汉字  
6. en 英文

### 块级元素与行内元素  
* 根据元素是否独占一行区分为块级元素和行内元素  
	1. 比如块级元素：``h1、p、div ...``  
	2. 比如行内元素：``span、input ...``  
* 使用规则：  
	1. 块级元素内能写：行内元素、块级元素(几乎什么都能写)  
	2. 行内元素中能写行内元素，不能写块级元素(可能效果正常，但是浏览器可能出现异常反应)  （a标签除外）  
	3. （之前的特殊规则）h1~h6不能互相嵌套  
	4. p标签中不能写块级元素

#### 格式化标签  
* 实际开发中格式化主要以CSS为主，这里实现类似的效果

### 图片标签  
* image是个单标签,默认行内元素  
* 此标签存在多个属性，属性之间用空格即可隔开(也可以使用换行符)  
	- src 图片路径：相对路径或者绝对路径或者URL  
	- alt 图片未能显示展示提示信息（语义：给浏览器标识此图片的含义-用于搜索引擎搜索）  
	- title 鼠标悬浮在图片上面的提示信息  
	- width、height控制图片宽度和高度 px为像素单位
		* 需要注意通常只控制一个就行，这样会按照图片本身大小进行等比缩放  
	- border 边框厚度  
```html
    <img src="./test.png" alt="当前未能正确显示图片" title="你的鼠标在图片上哦~" width="100px" border="10px">
```

* 图片存在多种格式：  
	1.** jpg** 有损压缩格式，不支持透明背景，不支持动态图  
	2. **png** 无损压缩格式，不支持动态图  
	3. bmp 不进行压缩，但是空间消耗巨大  
	4. **gif** 支持简单色彩透明背景(256)，支持动态图  
	5. **webp格式**，谷歌推出的兼容上述各种图片格式的图片，用于展示在网页上  
	6. base64 将图片转码为明文存储，通常适用于小的图片和随网页一起加载的图片（浏览器不会根据路径向服务器进行请求图片资源）  

### 超链接标签  
* a标签，行内标签  
* 存在属性设置  
	- href 指定url、文件、锚点链接(定位位置)**必备标签**  
		1. 指定url 常规页面跳转，跳转到指定网页即可(内部和外部网页均可)  
		2. 空链接 ``#``表示占位符  
		3. 内部文件路径，可以下载文件  
		4. 锚点链接：#idname 可以转移到当前html中id（或者name-name必须要写在a标签上 name也是不能重复的 id更加精准）标记的位置，标``#``可以直接回到顶部  
			- 另外可以在其他页面跳转描点，只需要对应html后面加#指定描点即可  
	- target 指定当前页面调整还是起新页面进行跳转  
		* 默认``_self``当前页面，否则``_blank``打开新标签页  
* 注意a标签内可以方任意的网页元素，点击会执行对应href  
* 注意：a标签除了a标签不能内嵌，**其余标签都能包含**(和默认的行内标签不能包含块级元素不同哦~)  
* 浏览器可以直接打开的文件会直接打开文件(图片、音频、pdf、mp4...)  
* 如果不能打开那么会触发下载(zip...)  
* 如果想直接触发下载：``download``即可   
* 唤起指定应用  
	1. 电话联系：``tel:电话``   
	2. 邮件联系：``mailtp:邮箱``  
	3. 短信联系：``sms:电话``

### 表格标签  
* table标签，表示整个表格  
	- 存在属性设置大小、边框等，一般使用CSS的方式进行设置  
	* align 是表格相对于周围元素的对齐方式. align="center" (不是内部元素的对齐方式)  
	* border 表示边框. 1 表示有边框(数字越大, 边框越粗，单元格边框不受此控制，最多只能为1px), "" 表示没边框  
	* cellpadding: 内容距离边框的距离, 默认 1 像素  
	* cellspacing: 单元格之间的距离. 默认为 2 像素  
	* width / height: 设置尺寸(高度改变不会牵引表头和表脚，并且是至少设置的尺寸)  
* ``tr``表示表格的一行  
	- height属性可以作用于此标签上  
	- align属性可以设置对其方式：水平方向的：left、right、center  
	- valign属性设置垂直方向的对齐方式：top、middle、bottom  
* ``td``表示表格的一个单元格  
	- width、height可以设置（遵循列对齐和行对齐）  
	- align、valign也可指定对齐方式  
	- 存在几个单元格进行合并的情况
	1. 跨行合并，向上进行合并，属性``rowspan="n"``  
	2. 跨列合并，向左进行合并，属性``colspan="n"``  
	- 注意上面的n均表示合并几个单元格  
	- 向上合并最终在原本的合并的第一行进行添加属性，向左合并最终在原本合并的第一列添加属性  
* ``caption`` 标签标识表格的标题  
* ``th``表示表头单元格，会居中并且加粗  
* ``thead``表格的头部区域(整个头部的区域，th只是一个单元格)  
	- height属性可以作用于此标签上  
	- align属性可以设置对其方式：水平方向的：left、right、center  
	- valign属性设置垂直方向的对齐方式：top、middle、bottom  
* ``tbody``表格的主体部分  
	- 属性和thead一致  
	- 需要注意height设置需要大于table中设置的最小值，一旦小于不会产生效果  
* ``tfoot``表格的脚注  

  - 属性和thead一致  
- 大概的常规表示方式：

		<tbody>

				<td></td>

### 列表标签  
* 用来布局，整体表现很好看  
* ``ul、li``无序列表  
	- ``ul``中只能存放列表标签``li``  
	- ``li``中可以存放任意标签  
* ``ol、li``有序列表  
	- ``ol``中只能存放列表标签``li``  
	- ``li``中可以存放任意标签  
* ``dl、dt、dd``自定义列表  
	- ``dl``表示总标签，里面只能放``dt、dd``  
	- ``dt``表示小标题  
	- ``dd``是围绕着标题进行说明的列表，术语描述

## html结构编码小技巧  
* 在遇到多组或者多代的结构，可以利用编码技巧轻松解决不必一个一个标签的去敲  
* 规则  
	1. 同级标签使用**+**并列写出  
	2. 多代标签使用**``>``**间隔，双方左边必须时父代，右边时子代  
	3. 生成div+class指定类名可以使用``.class``的格式，其中class换成你想要的类名  
	4. 同级多个标签如果是相同的标签可以使用**``*``**进行使用，比如3个div就是:``div*3``  
* 示例：``生成myclass的div标签，其中存在两个a标签、三个p标签、1个ul标签，里面存在3个li标签``  
	**``.myclass>a*2+p*3+ul>li*3``**  
```html
    <div class="myclass">
        <a href=""></a><a href=""></a>
        <p></p>
        <p></p>
        <p></p>
        <ul>
            <li></li>
            <li></li>
            <li></li>
        </ul>
    </div>
```

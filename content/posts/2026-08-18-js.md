# JS入门  
## JS简介  
* 起源源于网页上简单验证格式不需要通过服务器进行验证  
* 现在多用于制作网页上的动态效果  
* 实际上标准委员会制定的标准（ES）是需要不同的浏览器厂商进行实现的（js引擎）  
* 一个完整的js应该分为如下三个部分：  
	1. ECMAScript-标准  
	2. DOM-文档对象模型（网页）  
	3. BOM-浏览器对象模型（浏览器）  
* 特点：  
	1. 解释性语言(不需要编译)  
	2. 类似于C、Java的语法结构  
	3. 动态语言(类型)  
	4. 基于原型的面向对象  

## JavaScript-HelloWorld  
* JS代码需要包含在script标签中，type="text/javascript"(默认值)  
```js
	/* 弹出一个警告框 */
	alert("hello world");
	/* 让计算机页面中输出一个内容
     * 在body中输出一个内容
	 */
	document.write("Hello world");
	/* 向控制台输出一个内容 */
	console.log("hello world");
```

* Js同样是从上到下进行执行的  

## JS代码编写位置  
* 写在标签内。但是结构和行为耦合，不推荐使用  
1. 可以将js代码编写到标签的onclick属性中,点击此属性时执行js  
```html
	<button onclick="alert('讨厌，点我干嘛~');">点我一下</button>
```

2. 可以将js代码写在超链接href属性中(需要跟上javascript:代码)，点击超链接执行js代码  
	- 代码可以不用写，后面直接跟分号;，方便用于让超链接不调整，通过js设置一些功能  
```html
	<a href="javascript:alert('点我！')">你也点一下</a>
```

* 写在script标签中去  
* 写在外部文件中(js文件)，通过script标签进行引入  
	- 可以在不同的页面引入，并且能利用到浏览器的缓存机制  
	- script一旦用于引入外部文件，内部不能编写代码了，编写了浏览器会忽略。需要的话重新创建script  
	- defer的设置时让其延时加载  
```html
	<script defer src="路径"></script>
```

## Js基本语法  
1. 注释：``/**/和//``  
2. Js中严格区分大小写  
3. JS中每一条语句以;分号结尾  
	- 不写的话，浏览器会帮你自动添加（可能会加错）  
4. JS中会忽略多个空格和换行，我们可以利用这些对代码进行一个格式化控制  

## JS的字面量和变量  
* 字面量就是一个值，比如数字、字符串、true、null。字面量可以直接使用  
* 变量需要先声明，然后去使用。变量可以"存储"字面量，并且变量内的值可以任意修改  
	- **let** x声明x为变量，可以对其进行赋值和输出  
```js
	let x;
	x = 10;
	console.log(x);
```

### 变量的使用  
1. 声明变量  
	- let 变量名  
	- let 变量1, 变量2. 变量3  
	* var也可以进行声明变量(旧的方式-存在缺陷：**var的变量不存在块作用域** )  
2. 变量赋值(变量不存在类型)  

  - 变量名 = 值  
* 声明和赋值可以同时进行  
	- let 变量名 = 字面量;  
### 变量的的内存结构  
* 字面值会在内存中直接开辟空间存储（如果存在相同的不会进行创建），对应变量中存储对应值的地址（let、var相同类型，无法确定具体的值的大小）  

## JS的常量  
* 使用关键词const可以修饰常量，常量不可修改，定义和初始化必须同时进行  
```js
	const PI = 3.14159265;
```

* 当不想让一个值能够被修改，可以设置其为常量  

## JS的标识符  
* 在Js中，所有我们可以自主命名的内容，都可以认为是一个标识符  
	- 变量名、函数名、类名....  
* 使用标识符时，存在一些命名规范：  
	1. 字母、数字、下划线、$。并且不能以数字开头  
	2. 不能是js中的关键字和保留字，也不建议使用内置的函数或者类名作为变量名  
	3. ``[规范]``：  
		- 驼峰命名法:小驼峰  
		- 类名使用大驼峰  
		- 常量的字母全部大写  

# JS数据类型  
## 数值  
* JS中，所有的整数、浮点数都是Number类型（在浏览器控制台会显示成蓝色）  
* JS数值如果过大，不能精确的进行显示值，只能显示近似值  
* Infinity-表示数值的无穷大  
* 在JS中进行一些**精度比较高的运算**时要十分注意  
* NaN表示一个Not a Number，表示非法数字  
* 大整数-BigInt类型，可以用来表示一些比较大的整数  
	- 一个字面值可以后面跟上n即可  
	- 大小以内存为准  
	- 只能表示整数  
	- 大整数只能和大整数计算  
```js
	let a = 999999999999999999999999999n;
```

* 其他进制的数：  
	1. 二进制：0b  
	2. 八进制：0o  
	3. 十六进制：0x  
	- 注意输出出来的数字一定是10进制的方式进行显示的  

## 类型检查  
* 使用一个运算符可以对变量进行类型检查  
* ``typeof 变量``即可,根据不同的变量的值类型，返回不同的结果（检查的是变量内存储的值）  
```js
	console.log(typeof a);
```

## 字符串  
* 字符串在js中使用单引号或者双引号创建字符串  
```js
	let a = 'hello world';
```

* 字符串中显示"的时候可以使用转义字符：``\"``  
	- 存在其他转义字符（类比C）  
* 字符串如果想跨行，可以在一行的结尾增加反斜杠即可（兼容性不好），可以使用反单引号-模板字符串  
* 模板字符串：\`字符串\`  
	- 跨行使用  
	- 可以将变量的值嵌入到字符串中 ，内部使用${变量名}即可   
```js
	let name = '世界';
	let str = `你好,${name}`;
	console.log(str);
```

## 其他数据类型  
### 布尔值boolean  
* 进行逻辑值判断  
1. true真  
2. false假  
### 空值null  
* 使用typeof无法检测空值，会返回一个object  
### 未定义(Undefined)  
* typeof检测一个未定义值，返回一个undefined，并且其也可以进行赋值  
### 符号(Symbol)  
* let c = Symbol();  
* 可以创建一个符号，作为属性的标识  

## 类型转换  
* 将其他类型转换为（字符串、数值、布尔值）  
* 转换为字符串  
	1. 调用toString()方法转换为字符串（变量let存在方法-注意null和未定义值不存在此方法）  
	2. String(变量)进行转换（此时null和未定义值也可以进行转换）  
		- 原理，实际上这里是封装了调用对应变量toString，如果没有比如null会直接进行转换为'``"null"``  
* 转换为数值  
	1. 使用Number()函数将其他类型转化为数值  
		* 如果字符串是个合法的数字，会自动转换为对应的数字，否则设置为NaN（空串或者空格会转换为0）  
	2. 字符串中专门转换为数值的两个方法：  
		* parseInt(str)、parseFloat(str)  
		* 注意str中必须是字符串类型，并且会解析，会自左向右读取连续的有效的数字（如果第一个就是字母那么就全部失效了）  
		* 如果传的str不是字符串类型（会默认转换为字符串类型）  
* 转换为布尔值  
	1. 使用Boolean()函数将其他类型转换为布尔值  
		- 转换的情况：数值不为0即true，否则是false(0和NaN)，字符串空串是false  

# JS运算符  
## 算术运算符  
* 运算符可以来对一个或多个值进行运算  
* 算术运算符：``+ - * / **(幂运算) % ``  
* Js是弱类型的，运算过程中可能会出现隐式类型转换（操作数不为数值时）  
* 需要注意加法时，如果操作数存在字符串（两个），那么会将数值转换为字符串，进行字符串拼接（利用自动转换的技巧(不需要通过String方法)：a = true + ''）  

## 赋值运算符  
* 将右边的值赋给左边的变量  
* 存在配合赋值运算符的算术运算符``+= -= *= /= **= %=``  
* ``??=``表示空赋值（只有当变量为null或者undefined时才会进行赋值）  

## 逻辑运算符  
* ! 逻辑非  
* && 逻辑与 
	- 都是短路与，如果第一个为false，不会看后面的值   
* || 逻辑或  
	- 也是短路或，如果第一个为true，不会看后面的值  

## 关系运算符  
* ``> >= < <= == !=``  
* 如果两个都是字符串，会逐位的比较字符的Unicode编码，否则就都是比较数值  
* ``===``表示全等运算符  
	- 注意NaN不和任何值相等（包括它自身）  
	- 全等不会进行自动类型转换，如果两个值类型不同会直接返回false  
* ``!==``不全等运算符  
	- 同理，不会进行自动类型转换  

## 条件运算符  
* (条件)? 表达式1 : 表达式2

# JS流程控制  
## 代码块  
* 使用``{}``来创建代码块，代码块可以对代码进行分组  
* 区别：let声明得变量具有作用域，无法在对应代码块的外部进行访问（类似于全局和局部变量的意思）  
## 条件控制语句  
### if语句  
* ``if(条件表达式) 语句;``  
* 条件表达式为true执行语句，否则不执行  
* 控制多行代码需要使用块进行控制  
### if-else语句  
* ``if(条件表达式) 语句1; else if(条件表达式) 语句2; else 语句3;``  
* 对于NaN用普通的条件控制语句无法进行判断，可以使用函数isNaN函数进行判断  
### switch语句  
* ``switch(值) { case 值1: 语句1; [break;] case 值2: 语句2; [break;] defalut: 语句3; [break;] }``  
* 值是进行全等比较的  
## 循环语句  
### while语句  
* ``while(条件表达式) 语句;``  
### do while语句  
* ``do{语句;}while(条件表达式);``  
### for循环  
* ``for(初始化;条件判断;迭代进行){语句;}``
### 循环嵌套  
* 循环中可以嵌套其他循环  
### break和continue  
* break会终止最近的循环、switch语句  
* continue会终止当前次循环，执行下次循环  

# JS对象  
## 对象  
* 数据类型分为原始值(数值、大整数、字符串、布尔值、控制、未定义、符号)、对象  
* 原始值只能表示一些简单的数据，复杂数据（比如结构化数据）不能进行表示，这些通常是原始数据集合起来一起  
* 对象是JS中一种复合数据类型，相当于一个容器，在对象中可以存储各种不同的类型数据  

1. 创建对象  
	- let obj = new Object();  
		- 创建Object可以将new省略  
		- 对象中可以存储多个类型的数据，称作属性  
2. 对象添加属性  
	- obj.属性名 = 属性值;  
3. 读取对象中的属性  
	- obj.属性名;  
4. 删除属性  
	- delete obj.属性名  

5. 对象赋值小技巧：
* 保证对象赋值的时候，原本对象没有赋值的属性不丢弃  
	- ``this.info = {...this.info, ...dataObj};``  

## 对象的属性  
* 属性名：  
	1. 属性名实际就是一个字符串，没有什么特殊要求（如果不能直接使用，可以尝试["属性名"]进行调用），但是建议属性名按照标识符的规范命名  
	2. 也可以使用符号类型作为属性名（Symbol()符号对象），此时不能加.，直接加``[符号对象名]``，注意也不能``""``，直接写符号对象的变量名即可访问  
		- 使用Symbol添加的属性，是不希望被外界访问的属性（类似于私有对象？）  
	3. 使用``[]``去操作属性时，可以使用变量  
* 属性值可以是任意的数据类型  
* 检查对象是否包含某种属性：str in object对象; 返回一个bool值类型表示有还是没有  
## 对象的字面量  
* 可以通过一个``{}``表示一个对象的字面量，用于创建对象  
* 并且使用还能在定义的时候同时初始化属性  
```js
	let mySymbol = Symbol();
	let obj = {
		name: 'qihai', 
		['gender']: '男',
		[mySymbol]: '特殊的属性',
		hello: {
            a: 1,
            b: 2
		}
	};
```

## 枚举属性for-in  
* 将对象的所有属性全部获取: for-in语句  
* for-in循环执行多次，会将全部的属性拿出，每次会赋值给定义的变量，里面存的是属性名  
* 并不是所有的属性都可以被枚举，比如使用符号创建的属性  
```js
	for(let proName in 对象){
        语句...
	}
```

## 可变类型  
* 原始值都属于不可变类型，一旦创建无法修改  
* 对象值属于可变类型，即可以修改内存中实际的内容  
* 注意：  
	- 如果有两个变量同时指向一个对象，通过一个变量修改对象时，对另一个变量也会产生影响  
* 在使用变量存储对象时，因为很容易因为改变变量指向的对象，提高代码的复杂度。所以通常情况下，我们给对象变量增加const属性即可  

## 方法  
* 对象的属性值可以是一个函数，在对象中的属性如果是函数称作为此对象的方法。调用函数称作调用对象的方法  
* 函数赋值时，可以进行省略：
```js
	function a() {}
	let obj = {
        x: a,
        y: function(){}
	}
```
```js
	function a() {}
	let obj = {
        a,
        y(){}
	}
```


# JS函数  
## 函数  
* 函数(function)，函数实际上也是一个对象  
* 具有其他对象所有的地方，并且可以存储代码，并且需要的时候可以调用这些代码  
* 语法：  
	- function 函数名(参数){}  
* 调用函数：指向函数中存储的代码。函数对象(参数);  
* 函数类型为：function  

## 函数的创建方式  
1. 函数声明  
```js
	function test(参数){
        //...
	}
```

2. 函数表达式  
```js
	let fn = function() {
        //...
	}
```

* 实际上就是一个匿名函数  

3. 箭头函数  
```js
	() => {}
	() => 语句  
```

* lambda表达式  

## 参数  
* 定义函数时，可以在函数指定数量不等的参数  
* 在函数中定义参数，相当于在函数内部声明了对应的变量（形参）  
* 需要函数内的形参生效，需要在调用函数的时候将实参传参给形参即可  
* 注意：  
	1. 如果形参和实参数量相同，则对应实参赋值给对应的形参  
	2. 如果实参多余形参，多余的实参不会使用 
	3. 如果实参少于形参，则多余的形参赋值为undefined   
* 任何类型都可以作为参数进行传递  
* 参数可以给定默认值（每次调用都会重新创建默认值）  
* 参数传递的都是里面**存储的内存地址**--  
* 函数作为参数  
	* 动态的进行传递代码，函数式编程  

### 可变参数  
* 函数中存在另一个隐藏参数：arguments，是一个类数组对象（伪数组，可以像数组那样去操作，但是不能调用数组的方法）  
* 实际上arguments用来存储函数的实参，无论函数是否定义形参，实参都会存储到arguments对象中，可以通过该对象直接访问实参  
* 由于没有显示定义，js提供了一个类似的替代方案也就是可变参数：  
```js
	function sum(...args){
        
	}
```

* 箭头函数不存在arguments  
* 可变参数可以接受任意数量的实参，并且将他们统一存储到一个**数组args**中去  
	- 需要注意和arguments不同的是，形参定义可以配合可变参数进行配合使用，比如定义形参：a, ...args。此时第一个会给a、b，其余的参数才会给args（需要写在最后）  


## 函数的返回值  
* 使用关键字return返回返回值，并且不需要指定返回值类型  
* JS中任何值可以作为返回值使用  
* 当然return也可以作为终止函数的方式，不写返回值默认范围undefined的  
* 箭头函数的返回值可以直接写在箭头后  
	- 注意想要直接返回对象的化（如果对象使用:{name: 'test'}）这样就会出现冲突了，因为{}会被当作一个代码块了，可以在外面加上()即可  

## 作用域  
* 变量的可见区域  
* 作用域分为两种：  
	1. 全局作用域  
		- 在网页允运行时创建，网页关闭时消失  
		- 所有直接编辑到script标签的代码都位于全局作用域中  
		- 全局作用域中的变量是全局变量，可以在任意位置进行访问  
	2. 局部作用域  
		- 块作用域  
			* 代码块执行时创建，执行完毕就销毁  
			* 在块作用域中声明的变量，只能在内部访问，外部无法访问（var变量除外）  
		- 函数作用域  
			* 函数作用域在函数调用时产生，调用结束销毁  
			* 函数每次调用会产生一个全新的函数作用域  
			* 函数中定义的变量是局部变量，只能在函数内部访问，外部无法访问（包括var变量）  
### 作用域链  
* 当我们使用一个变量时，JS解释器会优先在当前作用域中寻找变量，找到了直接使用，如果没找到会依次从上面作用域去寻找，直到没找到-undefined报错  

## window对象  
* 浏览器中为我们提供了一个window对象，可以直接访问  
* window对象代表是浏览器窗口，通过该对象我们可以对**浏览器窗口**进行各种操作  
	- 除此之外，window对象还负责存储JS中的内置对象（String()、Namber()）和浏览器的宿主对象(alert()、console.log())  
* window中的属性可以通过window对象进行访问，也可以直接访问  
* 函数可以认为是window的对象的方法  
* 向window对象中添加的属性会自动成为全局变量  
* 实际上，var声明的变量就是window属性（let不会存储在window属性中） ，function声明的函数就是window的方法进行保存  
* 注意：在局部作用域中，如果不写var、let声明变量，并且外面作用域并没有存在，那么此时会被解释为window对象的属性  

## 提升  
* 变量存在提升-使用var声明的变量，会在所有代码块执行前先被提前声明  
* 函数存在提升-使用**函数声明**（function，不能进行赋值）创建的函数，会在其他代码执行前被创建（这就是函数在后面定义前面能够调用的原因）  
* 实际上let声明的变量也会提升，但是在赋值前禁止访问变量  
* 存在即合理，为什么会存在提升？  
	- 提前规划好内存空间，这样能够减少内存动态分配次数，减少性能消耗

## 立即执行函数

## this  
* 函数在执行时，JS解析器每次会传递一个隐含的参数，参数称作为this（全局作用域上调用的function，this就是window对象）  
* 方法->对象中的函数，this实际上就是对应调用的对象  
* 通过this，可以在方法中引用调用方法的对象  
	- 注意，在js里面，对象都是类似于json格式进行定义的，想要调用对应对象中属性，自然需要当前对象的一个变量，才能调用到对象中的属性  
* 注意箭头函数中的this：不会设置自己的this，由外层作用域决定（比如在全局作用域中声明，this固定就是window）-比较稳定，后续开发会经常进行使用  
* 总结：  
	1. 以函数形式调用，this是window  
	2. 以方法形式调用，this是调用方法的对象  
	3. 构造函数中，this是新建的对象  
	4. 箭头函数没有自己的this，由外层作用域决定  
	5. 通过call和apply调用的函数，他们的第一个参数就是函数的this（箭头函数无法修改this）  
	6. 通过bind返回的函数，this由bind的第一个参数决定（无法修改）（箭头函数无法修改this）  

### ``call``和``apply``  
* 调用函数除了xxx()的方法进行调用还可以使用函数名.call()和函数名.apply()两个方法进行调用函数  
* call和apply除了调用函数外，还可以指定函数的this，即将对象实例作为一个参数进行传递即可（第一个参数）  
* 对于call，除此指定this外，函数的实参可以接着后面进行一个一个传递  
* 对于apply，除此指定this外，函数的实参需要通过数组进行传递  

## JS的严格模式

	- 造成的影响：运行的性能较差。上述例子变量就不会首先统一的去开辟空间，而是执行到对应行去造成性能上的浪费  
* 严格模式，语法检查会变得严格  
	1. 禁止一些语法  
	2. 更容易报错  
	3. 提升性能  
* 在全局作用域下(开头)开启严格模式：``"use strict"``

* 开发中尽量的使用严格模式-消除隐患和提升代码的运行性能（健壮性）

## 闭包  
* 利用函数，可以隐藏不希望外部访问到的变量  
* 闭包：闭包就是能访问到外部函数作用域中变量的函数  
```js
	function outer(){
        let num = 0;
        return ()=>{
            num++;
            console.log(num);
        }
	}
```

* 使用场景：不希望别人访问的内容时可以使用闭包  
* 构成闭包的条件：  
	1. 函数的嵌套  
	2. 内部函数要引用外部函数的变量  
	3. 内部函数要作为返回值返回  
### 闭包的原理  
* 函数的外层作用域在函数创建的时候已经确定了（词法作用域），**和调用位置无关**  
* 闭包利用的就是词法作用域  
### 闭包注意事项  
* 闭包的生命周期：  
	1. 闭包在外部函数调用时候产生，每次都是产生全新的闭包  
	2. 在内部函数丢失时销毁（内部函数被垃圾回收了）  
* 主要是用来隐藏一些不希望被外部访问的内容  
	- 闭包需要占用一定的内存空间  
	- 相较于类，闭包比较浪费空间（类可以使用原型，闭包不能）  
* 需要次数少创建闭包

# 面向对象  
## 面向对象编程  
* 面向对象编程（OOP）  
1. 程序是干嘛的？程序就是对现实世界的**抽象**  
2. 对象是什么？  
	- 一个事物抽象到程序中后变成了对象  
	- 在程序的世界中，一切皆对象  
3. 对象的构成（现实生活中的事物：数据+功能）  
	- 属性  
	- 方法  
4. 面向对象编程：程序中的所有操作都是通过对象完成的  

## 类  
* 之前创建对象的方式：Object存在问题：  
	1. 无法区分对象的类型  
	2. 批量创建同类型的对象（相同属性和方法）存在代码复用粘贴  
* JS中可以通过**class**进行解决问题  
1. **类是对象模板**，可以将对象中的属性和方法直接定义在类中  
2. 语法：class 类名 {}  
  - 定义此类  
3. 通过类创造对象实例：new 类名()  
	- 调用类的构造函数创建对象  
4. 可以通过关键字instanceof检查一个对象是否由某个类创建  
	- 对象实例 instanceof 类名  

## 属性  
* 类的代码块，默认就是**严格模式**  
	- 类的代码是用来设置对象的属性，不是什么代码都能写  
	- 比如实例属性名字（弱类型），并且同时能够赋值（实例属性只能通过实例访问）  
		- ``class test{
            name = '你好';
            static hh = '这是静态属性';
		}``  
	- 还能通过static定义静态属性，在类中定义静态属性不能通过实例去访问，只能通过类名进行访问  
		- ``let a = new test();a.name;``访问实例属性  
		- ``test.hh;``访问静态属性  

## 方法  
* 方法也是一种属性，可以像添加属性那样去添加函数-作为方法  
```js
	class test{
		name = 'test';
		hello = function(){};
	}
```

* 另外也可以直接写函数名加参数函数体直接添加方法（实例方法）

* 同理，在函数名前面加上关键字static表示此方法是一个静态方法，需要通过类进行调用，静态方法中this指向的是当前类  

## 构造函数  
* 类中可以添加一个特殊的方法constructor，称作构造方法  
```js

        }
	}
```

* 会在构造实例的时候执行，方便用于创建对象时，传参能够初始化对象实例中的属性  

## 封装  
* 对象就是一个用来存储不同对象的属性  
* 对象不仅仅需要存储，并且还要负责数据的安全  
* 直接添加到对象中的属性，并不安全，因为他们可以任意的修改  
* 确保数据的安全：  
	1. 私有化属性：使用``#``开头变成了私有属性（类比于private）  
		- 私有属性只能在类内进行访问  
		- 注意私有属性必须进行声明，不能直接添加  
	2. 提供setter和getter方法开放数据操作  
		- 想要获得或者合法修改对应的私有属性，可以在类内部设置方法进行规范即可  
		- 当然，上面提供的方法是比较老的方法，可以利用语言提供的关键字，不通过方法而是像调用属性的那样去做轻便化的封装：  
			1. get关键字：get 私有属性名(){return this.#私有属性名;}  
			2. set关键字：set 私有属性名(参数){判断逻辑;this.#私有属性名 = 参数;}  

## 多态  
* 在js中不会检查参数的类型，所以这就意味着任何的数据都可以作为参数传递  
* 要调用某个函数、属性，无需指定类型，只需要对象满足条件即可  
* 注意：和强类型语言不同（比如C++中，多态是需要基于继承-基类对象去调用的，理由就是传参的时候，需要强类型挂钩，参数必须要指定类的类型，否则传参失败，实现不了不同的对象调用相同的属性或者方法得到的结果不同）  
* 多态为代码提供了灵活性  

## 继承  
* 关键词extends能够指定基类进行继承  
* 通过继承可以减少重复的代码，并且可以在不修改一个类的前提对其进行**扩展**  
	- 开发中存在OCP开闭原则：程序应该对修改关闭，对扩展开放  
* 在子类中，可以通过创建同名的方法来重写父类的方法  
	- 需要注意，如果重写构造函数，需要调用方法super()构造父类的实例（该传的参还是需要传的）  
	- 通过super也可以调用原本属于父类的方法  

## 对象的结构  
* 对象中存储属性的区域有两个：1.对象自身（直接通过对象添加的属性、x=y的形式）、2.**原型对象(prototype)**（ 还有一些内容会存储到其他对象中，比如方法的存储）  
* 对于原型对象，在对象中会存在一个属性地址进行存储，属性叫做：``__proto__``   
	- 当访问对象中的属性，优先在对象中进行访问，没有则去原型对象中去找  
	- 会添加到原型对象中的属性：  
		1. 在类中xxx(){}添加的方法位于原型中  
		2. 主动向原型中添加的属性和方法  

## 原型对象  
* 可以直接通过``__proto__``属性进行访问  

* 上述虽然可以直接访问，但是可以赋值，可能会导致不安全的后果，所以推荐使用：``Object.getPrototypeOf(对象)``-静态方法 

* 还能通过类访问当前类的实例原型对象：``类名.prototype``（``===__proto__``）   
	- 一般程序员通过这种形式在原型上放对象  

* 原型对象中的数据：  
  1. 对象的数据（属性和方法）  
  2. constructor（对象的构造函数）  

* 注意：原型对象也存在原型：``__proto__.__proto__``，构成了一条原型链，根据对象的复杂程度不同，原型链的长度也不相同  

* 原型链：读取对象属性，优先对象属性，如果没有去原型找（依次向上），直到找到Object对象的原型-（其没有原型），没找到返回undefined  
### 原型对象的作用  
* 所有的同类型对象，他们的原型对象都是同一个，也就意味着同类型的原型链也是一样的  
* 相当于同类型不同实例的公共区域，可以被所有的该类实例访问  
	- 在对象中有些属性的值是对象独有的，但是有些值比如方法都是一样的，所以这些一样的值没有必要重复的创建  
* JS中继承就是通过原型实现  
	- 继承时，子类的原型的原型就是父类的实例  
	- 这也是能够调用父类属性和方法的原因  

### 修改原型  
* 大部分情况下不需要修改原型对象  
* 可以通过对象，对原型添加方法，修改后同类型的所有实例都能访问该方法  
```js
	class test{
        
	}
	const p1 = new test();
	const p2 = new test();
	p1.__proto__.run = ()=>{console.log('我在跑');};  
```

* 注意：  
	1. 通过一个对象影响所有同类对象  
	2. 通过原型先得创建实例（不如静态属性）  

### 原型中的属性：``instanceof和hashOwn``  
* **instanceof用来检查一个对象是否是一个类的实例，实际上就是检查该对象的原型链上是否存在该类实例，就会返回true**  
* Object是所有对象的原型  
* **使用in运算符检查属性时，无论对象在自身还是原型中，都会返回true**  
* 对象.hasOwnProperty(属性名)用来检查一个**对象自身是否含有某个属性（除开原型）**（不推荐使用）  
  - **可以使用Object.hasOwn(对象, 属性名)**进行代替（现代js推荐）静态方法  
* 补充，创建一个没有原型对象的对象（和Object原型对象一致）  
  - Object.create(null);(上述hasOwnProperty()不推荐使用的原因就是这样的实例是调用不了此函数的，但是静态方法可以)  

## 旧类(了解)

# 数组  
## 数组简介  
* Array是内建对象，是一种复合数据类型，在数组可以存储多个不同类型的数据  
* 数据中存储的是有序的数据，数组中的每一个数据都有唯一的索引 
* 创建数组：``const arr = new Array();``/``const arr = []``  
	- 数组存在字面量为``[]``,类似于Object对象的字面量``{}``，并且可以定义的时候同时初始化值  
* 索引index是一组大于等于0的非负整数  
* 向数组中添加元素  
	- ``数组[索引] = 元素``  
	- 使用数组时，应该避免非连续数组，因为其浪费空间  
	- 元素可以是任意类型  
* 读取数组的元素  
	- ``数组[索引]``  
* 获取数组中元素的个数(最大索引 + 1)  
	- arr.length  
	- 可以利用此技巧向数组最后添加元素：``数组[数组.length]=元素``  
	- length是可以修改的？？？  
		* 改大和改小-改大存在多余空元素，改小多余的删掉  

## 遍历数组  
* 利用length作为最后条件，利用for循环遍历  
```js
	for (let i = 0; i < arr.length; ++i)
	{
        console.log(arr[i]);
	}
```

### for-of遍历可迭代对象  
* 语法：

```js
	}
```

## 数组的方法  
* 非破坏性方法：  
1. 检查一个对象是否是数组：Array.isArray();静态方法  
2. 通过索引获取数组中指定元素：arr.at(0);实例方法  
	- 可以接收负数作为索引，表示length - i的索引  
3. 连接两个或者多个数组：arr.concat(arr2);实例方法  
	- 不会影响原数组，返回新数组  
4. 获取元素在数组中第一次出现时的索引：arr.indexOf(var, index_start);  
	- 参数：1.查询的元素 2. 查询的起始位置  
	- lastIndexOf是从后往前查  
	- 返回值：如果没有找到返回-1  
5. 将一个数组中的元素连接为一个字符串：arr.join(str=',')  
	- 参数：str为元素之间的连接符，默认为,  
6. 截取数组（非破坏性方法）：arr.slice(index_start, index_end)  
	- 参数：截取起始位置，截取结束位置（不包括本身）  
	- ``[start, end)``  
	- end可以省略不写，默认截取到最后  
	- 同样的可以写负数  
	- 如果参数全部省略，则可以对数组进行一个**浅拷贝**  

* 破坏性方法：  
1. 向数组的末尾添加一个或者多个元素  
	- arr.push([元素1,元素2...])  
	- return当前数组的长度  
2. 删除并返回当前数组的最后一个元素  
	- arr.pop();  
3. 向数组开头添加一个或多个元素，并返回新的长度  
	- arr.unshift();  
4. 删除并返回当前数组的第一个元素  
	- arr.shift();  
5. 可以删除、添加、插入、替换数组中的元素  
	- arr.splice();

## 正则表达式  
* 正则表达式实际上就是定义一个描述字符串的规则  
* 通过这个规则计算机可以检查一个字符串是否符合规则，或者将字符串中符合规则的内容提取出来  
* 正则表达式在JS中也是一个对象  
* 创建正则对象：  
	* 通过new RegExp()创建一个对象（注意不传参是没有设定规则的正则）  
		- 接受两个参数（字符串）：1.正则表达式 2.匹配模式  
	* 使用字面量进行创建正则表达式：let reg = /正则/匹配模式;(均是字面量)  
* 方法：  
	- reg.test(str); 测试字符串是否符合规则  

### 正则表达式的规则  
* 正则：  
    1. 正则表达式中，大部分字符可以直接写，表示是否存在这些字符（顺序不可变）  
    2. 加上|表示两边字符存在一个即可-或  
    3. []表示或（字符集），表示内部字符相当于每个字符（一个）之间加上了|  
        - 字符集中"a-z"就可以表示任意的小写字母，"a-zA-Z"表示任意的字母  
        - 0-9表示任意数字  
        - 字符集内a-z、0-9可以任意组合，之间相当于均由|间隔，任意一个成立即可  
        - [^]表示除开里面设定的字符集  
    4. ``.``表示除了换行符以外的其他所有字符  
    5. 正则表达式中，使用``\``作为转移字符  
    6. 其他的字符集：  
    	- ``\w``任意单词字符===[A-Za-z0-9_]    
    	- ``\W``除了单词字符====[^A-Za-z0-9_]  
    	- ``\d``任意数字  
    	- ``\D``除了数字  
    	- ``\s``空格  
    	- ``\S``除了空格  
    	- ``\b``单词边界  
    	- ``\B``除了单词边界  
    7. 开头和结尾：  
    	- ^开头 可以配合开始位置的字符``/^a/``    
    	- $结尾 可以匹配结束位置的字符``/a$/``    
    	- ``/^xxx$/`` 完全匹配，字符串必须和其一样  
* 匹配模式：  
	- i忽略正则里的大小写  
	- g全局匹配（返回多个符合匹配规则的字符集）  
		* 注意一次返回一个，需要循环去匹配  

* 量词：
	- /单个字符{数量}/ 表示字符需要正好这个数量  
		* /^单个字符{数量}$/ 需要完全进行匹配  
		* 需要控制多个字符使用括号进行包裹：/(ab){3}/  
		* 单个字符也可以写字符集[]  
	- {m} 正好m个  
	- {m, }至少m个  
	- {m, n} m到n个  
	- + 表示一个以上：{1, }  
	- * 任意数量a  
	- ?  0~1次 {0, 1}  

* 提取字符串中的指定内容  
	- 使用exec函数，可以将字符串中指定规则符合的内容提取出来  
	- 返回的是一个数组  
	- 可以利用括号对匹配的内容进行分组，存在几个括号会匹配几组（全部的//里面的不写括号也会默认匹配到一组，也就是至少一组）(顺序是第一个1取第一个括号，2是第二个...依次类推)  
	- 全局匹配的话可以利用while循环判断每次取出来是否有值将所有匹配到的字符取出  
```js
	let str = "abcaccaecasc";
	let reg = /a[a-z]c/ig; // 匹配axc，x为任意字母 注意默认情况下只会匹配一个字符串，使用g可以全局匹配=注意一次返回一个，需要循环去匹配
	cosole.log(reg.exec(str));
```

	- "dajsdh13715678903jasdlsadasdsa13757890657asdasdsadas17632459835asdas"

# 事件循环  
* event loop：函数每次执行的时，会产生一个执行环境，执行环境负责存储函数执行时产生的一切数据  
* 函数的执行环境存储到哪里呢？- 调用堆栈  
## 调用栈  
* call stack  
* 栈是一种数据结构，特点：后进先出  
* 当一个函数被调用时，它的执行环境会作为一个栈帧， 插入到调用栈的栈顶，函数执行完毕会自动弹出  
## 消息队列  
* 队列和栈相反：先进先出  
* 消息队列负责存储将要执行的函数  
* 当触发的一个事件的时候，其响应函数并不是直接添加到调用栈中，因为可能存在一些没有执行完的代码  
* 事件触发后，JS引擎是将事件响应函数插入消息队列中排队（当栈空就会进入调用栈）  

# DOM  
* Document Object Model 文档对象模型，将JS和网页进行联系起来（WebAPI中的）

## 文本节点  
* 在DOM中，所有的文本内容都是文本节点对象  
* 对于一个标签内的文本对象，我们可以通过获取其标签，然后取出里面的子节点对象即可  
	- document.getElementByTagName("h1").firstchild;  
	- 但是这样做比较麻烦，可以直接通过元素对象直接修改其中的文本。  
* 修改文本的三个属性：  
	1. element.textContent; 获取或修改元素中的文本（会将内部文本外面包裹的标签去掉）  
	2. element.innerText; 获取或修改元素中的文本内容（会将内部文本外面包裹的标签去掉）  
		- 注意前两种会忽略标签，包括写入内容含标签标签符号会被进行转义显示出字符串  
		- textContent获取的是标签内的内容，不会考虑css样式  
		- innerText获取内容会考虑到css的样式，比如display等  
		- 通过innerText去读取css样式，会触发网页的重排（计算css样式）  
	3. element.innerHTML; 获取和修改原元素中的html内容  
		- 这里相当于直接在结构中增加HTML代码  
		- innerHTML插入内容时，有被**xss注入**的风险（即可能会被用户插入一段script脚本代码，导致插入到当前网站进行生效）  

## 属性节点

* 操作属性节点：  
	1. 方式1：  
		- 读取：元素.属性名（注意class属性需要使用className进行读取）  
			* 注意，读取一个布尔值属性（比如input标签内的disabled属性表示禁用）会返回布尔值  
		- 修改：元素.属性名 = 属性值  
	2. 方式2：  
		- 读取：元素.getAttribute(属性名);  
		- 修改：元素.setAttribute(属性名, 属性值);  
		- 删除：元素.removeAttribute(属性名);  

## 事件  
* event-事件：用户和页面之间发生的交互行为  
	- 比如：点击按钮、鼠标移动、双击按钮、敲击键盘、松开按键...  
	- 可以给对应的事件绑定响应函数（回调函数），来完成和用户之间的交互  
* 绑定响应函数的方式：  
	1. 直接在元素中设置属性  
		- onclick点击 ondblclick双击 onmouseenter鼠标进入...  
	2. 可以通过元素的指定属性设置回调函数的方式来绑定事件  
		- 流程：获取到对应的元素对象，为按钮对象的事件属性设置响应对象即可  
		- 一次事件只能绑定一个响应函数  
	3. 通过元素的addEventListener()方法来绑定事件（通用性最好）  
		- 参数：事件名(上面的事件属性去掉on即可)、回调函数、是否以事件捕获进行触发函数  
		- 一次事件可以绑定多个响应函数，意思是响应函数不会进行覆盖，而是累加  

* 在事件绑定函数中，this的执行就是绑定其元素的对象（不建议使用这个）  
	- 注意箭头函数除外  

* 常用事件：  
	- onchange改变事件(input中的多选框...)  
	- onmousemove鼠标移动  
	- onmouseenter鼠标进入  
	- onmouseleave鼠标离开  
	- 按键事件：keydown、keyup（键盘事件只能绑定给可以获取焦点（超链接、表单等元素）的元素或者document）  
	- 滚动事件：scroll(上下和鼠标滚轮均可)、wheel（鼠标滚轮）  
	- 失去焦点：onblur  

### 超链接跳转事件  
* 注意超链接onclick存在默认行为即跳转到href指定的URL，我们可以利用下面几种方式阻止超链接默认的跳转行为：  
1. 可以在绑定onclick事件函数中return false，但是只能在xxx.xx = function(){}这种方式中存在，其余方式诸如addEventListener、onclick=""均不可（局限）  
2. 在超链接标签的属性href中写入"javascript:;"也能阻止超链接的默认跳转行为  
3. 可以通过事件对象的方法进行取消默认跳转：event.preventDefault(); 取消默认行为  

### 事件对象
* 上述事件发生时候，只能直到事件是否发生还是没有发生，但是并不知道里面的细节，比如鼠标移动事件发生后，我们需要直到鼠标的一个具体位置。此时需要用到事件对象  
* 事件对象是由浏览器在事件触发时创建对象，这个对象封装了事件相关的各种信息  
	- 通过事件对象我们可以获取事件的详细信息：鼠标坐标、键盘的按键...  
	- 浏览器在创建对象后，会将事件对象作为响应函数的参数传递，所以可以在回调函数中定义一个形参进行接收（一般名字为event）  
#### 事件对象介绍  
* 详细的可以获取到对应的对象，然后在MDN上查找文档进行学习即可  
* 在DOM中存在多种不同的类型的事件对象：多个事件对象存在一个共同的祖先：Event  
* 事件的冒泡（bubble）  
	- 事件的冒泡就是事件的向上传导  
	- 当元素上的某个事件被触发后，其祖先元素上的相同事件也会同时被触发  
	- 冒泡的存在大大的简化了代码的编写，但是在一些场景下我们不希望冒泡的存在  
		* 可以通过事件对象取消冒泡 evenet.stopPropagation(),可以取消事件的传导  
	- 事件的冒泡和样式无关，和结构相关  
* Event对象  
	- event.target属性，表示触发事件的节点对象（类似于响应函数中的this指针）  
		* 区分，this是绑定该函数的节点对象，但是target表示触发的对象，由于存在事件冒泡，所以有可能是其节点的子节点触发了事件  
	- evenet.stopPropagation(),可以取消事件的传导（到达当前元素结束，不会将相同事件传递到祖先元素上去）  
	- event.currentTarget 当前的对象-和this一致，表示绑定事件对象  
	- event.preventDefault(); 取消默认行为  
#### 事件的委派  
* 实际上，可以利用事件的冒泡，给一堆类似的子节点绑定同样的事件的场景下，可以给他们的祖先元素绑定相同的点击事件，即可实现。（未来新增的同样触发）  
* 但是注意，祖先元素，由于其存在范围问题，会导致其出现其他多余的功能，即多绑定了，实际上我们只是想让其内部的子元素生效其余不生效罢了  
* 解决：  
	- 回调函数中做出判断（利用数组检查是否存在的方式（数组为你想要生效的元素对象数组））   
* 委派就是绑定给多个元素的事件，统一绑定给document（内部通过条件判断是否触发）。方便管理，降低代码的复杂度方便维护  

#### 事件的捕获  
* 事件的传播机制：  
	- 在DOM中，事件的传播可以分为三个阶段：  
		1. 捕获阶段（由祖先元素向目标元素进行事件的捕获）  
		2. 目标阶段（触发事件的对象）  
		3. 冒泡阶段（由目标元素到祖先元素进行事件的冒泡）  
	- 事件的捕获：值事件从外向内的传导，当我们当前元素触发事件以后，会从当前元素最大的祖先元素开始向当前元素开始进行事件的捕获（省脑：从外到内）  
	- 默认情况下，是在事件冒泡的时候进行触发事件  
		* 可以设置addEventListener的第三个参数设置为true;  
		* 一般情况下这个需求很少，不会写  
* 可以通过属性：eventPhase可以查看事件对象的触发时机  
	- 0表示没有触发事件  
	- 1表示捕获阶段  
	- 2目标阶段  
	- 3冒泡阶段  


## 文档的加载  
* 注意网页是自上向下进行加载的，如果将JS代码编写到网页的上面，JS代码在执行的时候，网页并没有加载完毕，那么此时就出现了DOM对象获取不到的情况  
* 如何解决？  
	1. 将script标签写在body中的最后面  
	2. 写在最上面，并且让网页加载完成后执行：window.onload事件会在窗口中的内容加载完毕后触发  
		- 可以将js代码写入此事件的回调函数中，就可以将script标签放入head标签中了  
		- 会等到当前窗口的所有文档加载完毕后才会触发  
	3. 代码编写在document对象的DOMContentLoaded的回调函数中（注意是属于doc的事件）  
		- 注意document的DOMContentLoaded是会在当前文档加载完毕后触发  
		- 执行时机更早  
	4. 将代码编写到外部的js文件，然后以defer的形式引入（通用）  
		- ``<script defer src="js文件路径"></script>``  
		- 会让外部js文件进行一个延时加载（时机比dom事件更早）

## 节点的复制  
* 在上述添加到对应元素的节点的方法是直接移动，并没有进行复制。有的时候我们需要一个复制的场景

## 通过JS操作CSS样式  
### 修改元素的样式  
* **元素对象.style.样式名 = 样式值;**（存在耦合的问题-内联，并且如果改多个属性的话代码修改麻烦）  
* 注意：  
	- 如果样式名中含有-，则样式需要修改为小驼峰命名法（background-color->backgroundColor）  

* 上述存在局限，我们可以通过在css中设置类选择器设置好样式，在js中给对应元素增加class属性即可达到修改样式并且不涉及内联样式的方法（注意添加的话需要+=并且留下适当的空格哦） 
* 通过class修改的好处：  
	1. 可以一次性修改多个样式  
	2. 可以对JS和CSS进行解耦  
* 修改class的时候使用元素.className不是很优雅，可以通过下面的方式对class进行修改：  
	- 元素.classList是一个对象，对象中提供了对当前元素的类的各种操作方法  
	- 方法：
		1. add添加一个或多个class名，参数是可变参数，可以传入多个  
		2. remove移除一个或多个class名  
		3. toggle切换一个class名（存在就删除，没有就添加）  
		4. replace替换一个class名（两个参数，第一个为指定的class名，第二个为新的class名）  
		5. contains检查元素中是否包含指定的class  

### 读取元素的css样式  
* 首先元素对象.style.样式也能进行读取（但是只能设置内联样式才能读取，通常情况下读取不使用这种方式，太局限了）  
* 我们现在想读的是让当前元素**生效的样式**  
* 下面的读取样式的方法，均都是**只读**的，不可修改  
* ``getComputedStyle(元素对象);`` 返回一个对象，此对象包含了当前元素所有生效的样式  
	- 获取指定的样式属性：**对象.样式属性**即可获取  
	- 参数：  
		1. 要获取的对象  
		2. 要获取的伪元素（要获取对应元素对象的伪元素需要传入一个伪元素-字符串("::before")）  
	- 注意：
		1. 注意属性名也遵循小驼峰命名法  
		2. 有的样式属性获取默认值是实际值，有的时候是一个字符串  
* 高度和宽度可以通过元素对象的属性进行读取：  
	1. 元素.clientHeight/Width 获取可见元素内部的宽度和高度（包括内容区和内边距）-返回的就是数值  
	2. 元素.offsetHeight/Width 获取元素可见框的大小（包括内容区、内边距和边框）  
	3. 元素.scrollHeight/Width 获取元素滚动区域的大小  
	4. 元素.offsetParent 获取元素的定位父元素（注意定位元素找的要求是需要设置定位-包含块）  
	5. 元素.offsetTop/Left/... 获取元素相对定位父元素的偏移量  
	6. 元素.scrollTop/Left/... 获取或设置元素滚动条的偏移量（滚动条的滚动位置），可以对滚动条的位置进行修改控制位置

            		* 需要注意，当我们按下某个键不松开时，按键的按下事件会持续触发：但是这之中第一次和后面的触发存在很大的间隔时间-明显卡顿感  
  	* 优化蛇的移动：1解决卡顿 2贪吃蛇不可停止  
        		- 根本原因：按键连续触发事件防止误操作第一次有个卡顿现象  
                		- 换个思路，我们知道一个物体位移需要方向和速度，那么我们让事件只决定方向不就好了？并且设置一个速度，这样一直移动的问题也能解决了  
            		- 使用一个定时器代替循环函数，能够控制持续移动，并且通过方向，按键只是决定方向（多少ms执行一次来控制速度）  
                       		- 注意需要控制按键设置方向的时候不能存在其他按键干扰

    * 简单思路：判断当前蛇头和食物的坐标是否一致（均检查偏移距离是否一致即可）  
    * 碰撞到食物后蛇的事情：

    			* 优化分析：无论上拐，下拐左拐右拐，都只动最后一个格子的位置到当前蛇头的位置即可，其余（包括蛇头）均不动即可

```js
            // 由于宽度为300px，蛇的每帧移动10px，所以只能取值0~290，并且为10的整数
            let x, y;
            do{
                x = Math.floor(Math.random() * 30) * 10;
                y = Math.floor(Math.random() * 30) * 10;
            }while(snakeOverlap(snakes, x, y));
            // 此时找到不和蛇身体重合的地方了
            foot.style.left = x + "px";
            foot.style.top = y + "px";
        }


        // 通过DOM获取对象
        const snake = document.getElementsByClassName("snake")[0];
        const snakes = snake.children;
        const foot = document.getElementsByClassName("foot")[0];
        const score = document.getElementById("score");
        const level = document.getElementById("level");

        // 设置初始种子随机位置
        changeFootPos(snakes, foot);

        // 综合变量区域
        let dir = " ";  // 方向
        let snakeHead, snakeEnd;  // 蛇的头部和尾部对象
        let x, y;  // 相当于游戏窗口的x偏移和y偏移
        let isMove = true;
        let gameOver = false;// 游戏是否结束
        let gameScore = 0, gameLevel = 1;

        // 方向操控键：w上s下a左d右
        const moveKeys = ["w", "s", "a", "d", " "];
        const dirReverses = {
            w: "s",
            s: "w",
            a: "d",
            d: "a",
            " ": 0
        };
        // 给网页绑定检测按钮事件
        document.addEventListener("keydown", (event)=>{
            if (isMove && moveKeys.includes(event.key))
            {
                if (snakes.length < 2 || (dirReverses[dir] != event.key))
                {
                    dir = event.key;
                    if(dir != " ") isMove = false;
                }
            }
        });

        // 触发定时器，让蛇能自动走，根据获取键盘的方向，速度由间隔时间决定
        setTimeout(function move(){
            if (!gameOver && dir != " ")
            {       
                // 获取当前蛇的头部
                snakeHead = snakes[0];
                x = snakeHead.offsetLeft;
                y = snakeHead.offsetTop;

                switch (dir) {
                    case "w":
                        y -= 10;
                        break;
                    case "s":
                        y += 10;
                        break;
                    case "a":
                        x -= 10;
                        break;
                    case "d":
                        x += 10;
                        break;
                    default:
                        break;
                }

                // 判断当前蛇是否吃掉了食物
                if(x === foot.offsetLeft && y === foot.offsetTop)
                {
                    changeFootPos(snakes, foot);
                    snake.insertAdjacentHTML("beforeend", "<div></div>");  // 增加身体

                    gameScore += 5;
                    score.textContent = gameScore;
                    if (gameLevel < 5 && gameScore % 20 === 0)
                    {
                        gameLevel++;
                        level.textContent = gameLevel;
                    }
                }

                // 判断当前蛇是否和墙发生了碰撞或者撞到了自己
                if (x < 0 || x >= 300 || y < 0 || y >= 300 || snakeOverlap(snakes, x, y))
                {
                    console.log("gameover!");
                    gameOver = true;
                }
                else{
                    // 设置当前蛇的尾巴元素到当前移动的位置
                    snakeEnd = snakes[snakes.length - 1];
                    snakeEnd.style.left = x + "px";
                    snakeEnd.style.top = y + "px";
                    snake.insertAdjacentElement("afterbegin", snakeEnd);  // 插入到第一个去，此时结构也发生了变换
                }
                
                isMove = true;
            }
            setTimeout(move, 300 - 70*(gameLevel-1));
        }, 300 - 70*(gameLevel-1));


    </script>
</body>
</html>
```


# BOM  
* 浏览器对象模型。BOM为我们提供了一组对象，可以通过这组对象可以完成对浏览器的各种操作  
* BOM对象：  
	- window对象 - 浏览器窗口（全局对象）  
	- Navigator - 浏览器对象（可以来识别浏览器）  
	- Location - 浏览器的地址栏信息  
	- History - 浏览器的历史记录（控制浏览器前进后退）  
	- Screen - 屏幕信息  
* BOM对象都是作为window对象的属性进行保存的，所以可以直接在JS中访问这些对象  

## Navigator浏览器对象  
* 建议查文档，这里只是简单介绍  
* userAgent属性，返回一个用来描述浏览器信息的字符串  

## Location浏览器地址栏信息  
* 可以直接修改location为一个新的地址，这样会让网页直接跳转  
* location.href获取当前地址栏内的地址  
* 其余属性是对地址各个部分的分开解析  
* 方法：  
	1. location.assign("URL")和直接给对象复制一致，跳转到新的地址  
	2. location.replace("URL")类似效果，但是无法回退（无历史记录）  
	3. location.reload(); 刷新页面，参数传递true的话，可以强制清除当前网页的缓存  
## History历史记录  
* 属性：  
	- length 基于当前页面的访问不同网页次数  
* 方法：  
	- history.back(); 回退到上一个网页  
	- history.forward(); 快进到下一个网页  
	- history.go(n);n控制前进几个还是后退几个页面（后退使用负数）  

# 浏览器本地存储  
* window上存在一个对象**localStorage**,调用它身上的api，能够让浏览器帮助我们缓存一些网页数据到本地（存储大小支持5MB左右）  
	- 使用api**存储**：``localStorage.setItem('key', 'value')``即可  
		* 注意value和key均是以字符串的形式保存的，如果对象需要保存请务必使用Json.stringify()转换为JSON格式的字符流进行存储  
	- 使用api**读取**：``localStorage.getItem('key')``  
		* 如果读取的是对象，则需要使用JSON.parse()对其进行解析为对象  
		* 注意如果没有值返回的结果是null  
	- 使用api**删除**：``localStorage.removeItem('key')``  
	- 使用api**清空**：``localStorage.clear()``  
* 注意上述localStorage的api均是持久化存储（用户会清空浏览器的缓存）  
* 同样的，window还存在一个对象。**sessionStorage**，表示浏览器一次会话的存储，api和localStorage一致，区别就是不是持久化存储

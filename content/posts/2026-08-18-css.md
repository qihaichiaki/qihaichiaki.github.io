## CSS是什么?  
* 它是层叠样式表(Cascading Style Sheets)  
* 层叠：一层一层的**涂**上去的  
* CSS能够够对网页中元素位置的排版进行像素级精确控制, 实现**美化页面**的效果. 能够做到**页面的样式和结构分离**  

## 基本语法规范  
```css
	选择器 {
        /* 一条/N条声明*/
        key: value;
        /*... */
	}
```

* 想象一下，我们需要针对html结构进行排版控制，那么我们首先需要先找到，其次对它的什么属性进行控制(键值对)  
	- 寻找：**选择器**  
	- 控制: **属性:具体值**  
> 注意每个属性设置最后需要加上**;**作为结束标志  
> CSS不区分大小写，我们以小写为主  
> 键值对:后需要加上一个空格，选择器之间和``{``之间也需要一个空格  

* 实例，我们选择html的结构部分中的p标签，对其内容值颜色修改为红色，字体大小设置为30px  
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS样式控制示例</title>
    <style>
        p {
            color: red;
            font-size: 30px;
        }
    </style>
</head>
<body>
    <p>你好&nbsp;我只是一个简单的一行</p>
</body>
</html>
```

- 注意:  
	1. CSS的内容在``<head></head>``标签内以``<style></style>``形式进行引用  
	2. CSS中可以以``/**/``的方式进行注释，``//``是不行的  

* 那么在考虑如何对html结构进行样式的修改时，应该考虑如何引入CSS的代码(上面的style标签实际上已经提供了一种方法)  
## CSS的引入方式  
1. 内部样式表  
	* 一般可以将CSS写入**style**双标签内，在html结构中任意地方进行引入(一般放在head标签内)  
	> **优点**: 能够做到让样式和页面结构进行分离  
	> **缺点**: 分离的还是不够彻底,特别是当CSS内容多的时候  

	* 例子：<a href="#基本语法规范">就是前面基本语法示例举的例子</a>  

2. 行内样式表  
	* 通过本身标签内的属性**style**来指定样式  
	> **优点**：适合于写简单的样式  
	> **缺点**：不能写太复杂的样式，并且根据就近原则，此样式的针对对应标签的优先级最高，会覆盖外部的设定的样式  

	* 例子:  
```html
	<!-- ... -->
	<body>
			<p style="color: green;">你好，我不是红色，我是绿色</p>
	</body>
```

3. 外部样式  
	* 实际开发中最常用的样式  
	* 通常在本地目录创建一个CSS文件(后缀为.css)，Html结构中在head标签内通过link标签进行引入  
	* link标签引入格式: ``<link rel="stylesheet" href="[CSS的文件路径]">``  
	> **优点**: 样式和结构彻底的分离，存在浏览器缓存，不同html文件引入相同css文件访问速度会加快  
	> **缺点**: 受到浏览器缓存影响，修改后**不一定**立即生效  
	> 此缺点可以通过ctrl+F5强制刷新页面，让浏览器重新获取CSS文件进行解决  

	* 例子：  
- css文件  
```css
h1 {
    color: blue;
    font-size: 60px;
}
```
- html文件  
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS样式控制示例</title>
    <style>
        p {
            /*这里是红色内容和字体大小控制的属性*/
            color: red;
            font-size: 30px;
        }
    </style>
    <link rel="stylesheet" href="./test.css">
</head>
<body>
    <h1>我是标题，我很大</h1>
    <p>你好&nbsp;我只是一个简单的一行</p>
    <p style="color: green;">你好，我不是红色，我是绿色</p>
</body>
</html>
```

* 后续的示例均以外部样式的方式进行展示，html中只是展示结构，做到样式和结构完全分离  
* 样式表的优先级：  
	1. 行内样式优先级最高，内部样式和外部样式同级(同级受顺序覆盖影响)  
	2. 相同属性才会存在覆盖的动作

## 选择器  
* 选择器的作用**就是为了确认目标标签**，从而通过修改属性对其做到精确的样式控制  
* 下面通过学习选择器的种类来对选择器进行进一步的学习，学习到多种复杂的结构状态下如何精准的选择到想要的标签  
* 选择器的种类  
1. 基础选择器(单个选择器构成)  
	- 标签选择器  
	- 类选择器  
	- id选择器  
	- 通配符选择器  
2. 复合选择器(多种基础的选择器综合应用起来)  
	- 后代选择器  
	- 子选择器  
	- 并集选择器  
	- 伪类选择器  
* 针对基础选择器，实际上就是对于标签中的属性进行区分和筛选，标签本身字符、class属性、id属性等  
### 基础选择器  
1. 标签选择器  
* 特点:  
	- 能快速将同一类型的标签都选出来  
	- 不能差异化选择  
```css
h1 {
    color: red;
}
p {
    color: blue;
}
```
```html
    <!-- 标签选择器 -->
    <h1>我是标题标签</h1>
    <h1>我是标题标签</h1>
    <h1>我是标题标签</h1>
    <p>我是段落标签</p>
    <p>我是段落标签</p>
    <p>我是段落标签</p>
```

2. 类选择器  
* 特点:  
	- 可以差异化的选择不同的标签  
	- class标签内的属性可以重复，所以利用class属性也可以选择自定义的一批标签  
	- 类选择器的时候类名前标上``.``即可  
```css
.class1 {
    color: red;
    font-size: 30px;
}

.class2 {
    color: blue;
    font-size: 20px;
}
```
```html
    <!-- 类选择器 -->
    <p class="class1">我是类1</p>
    <h1 class="class1">我是类1</h1>
    <p class="class1">我是类1</p>
    <p class="class2">我是类2</p>
    <a class="class2" href="#">我是类2</a>
```
* 注意：  
> class标签属性中类可以多个复用，不同的类名之间用空格隔开，可以做到更好的代码复用  
> 不要使用纯数字、中文、标签名来命名类名  

* 多类名控制示例  
```css
.red {
    color: red;
}
.blue {
    color: blue;
}
.green {
    color: green;
}
.big {
    font-size: large;
}
.mid {
    font-size: medium;
}
.small {
    font-size: small;
}
```
```html
    <!-- 多类名控制 -->
    <p class="red big">你好，这里是第一行</p>
    <p class="blue mid">你好，这里是第二行</p>
    <p class="green small">你好，这里是第三行</p>
```

3. id选择器  
* 特点:  
	- 和类选择器类似，只不过用**#**作为区分(类比学习：``<a href="#id"></a>``a标签中的定位功能**#**也是指向的id属性值)  
	- 需要注意id在html中是唯一的(和类最大的区别)  
	- id不能以数字开头  
```css
#red {
    color: red;
}
#blue {
    color: blue;
}
#green {
    color: green;
}
```
```html
    <!-- id选择器 -->
    <p id="red">我是唯一的红色</p>
    <p id="blue">我是唯一的蓝色</p>
    <p id="green">我是唯一的绿色</p>
```

4. 通配符选择器  
* 比如``*``的作用于选择器上可以选取全体标签  
```css
* {
    color: blueviolet;
}
```

### 复合选择器  
1. 后代选择器  
* 又称作包含选择器，选择某个父元素中的某个子元素  
* ``元素1 元素2 ... {样式声明}``  
* 实际上最终确认的是最后一个元素指向的标签，不影响前面的标签  
* 注意包含的是最后一个元素中的所有内容，同样的元素之间只需要保证前面的元素是后面元素的长辈即可(父 子... 也可以是父 孙)  
* 注意元素可以是任意的基础选择器的组合(标签选择、类选择、id选择)  
* 样例:将``ol>li``中的内容修改为red颜色，而``ul>li``不受影响  
```css
ol li {
    color: red;
}
ol a {
    color: red;
}
```
```html
    <!-- 后代选择器 -->
    <ol>
        <li>aaa</li>
        <li>bbb</li>
        <li><a href="#">ccc</a>c</li>
    </ol>
    <ul>
        <li>ddd</li>
        <li>eee</li>
        <li>fff</li>
    </ul>
```

2. 子选择器  
* 和后代选择器类似，但是后代选择器后面元素可以是前面元素的后辈，但是子选择器后面面元素必须是前面元素的子辈  
* 使用``>``符号进行分割，区别于后代选择器的``' '``  
* 下面是和后代选择器和子选择器的一个区分  
```css
.offspring a {
    color: red;
}
.child>a {
    color: red;
}
```
```html
    <!-- 子选择器 -->
    <div class="offspring">
        <a href="#">你好呀</a>
        <p><a href="#">这里是链接标签</a></p>
    </div>
    <div class="child">
        <a href="#">你好呀</a>
        <p><a href="#">这里是链接标签</a></p>
    </div>
```

3. 并集选择器  
* 用于选择多组标签(集体声明)  
* ``选择器1, 选择器2 {样式声明}``  
* 通过逗号分割不同的元素，让其存在相同的样式声明  
* 之前的选择器可以成为其中的元素用于并集选择器  
* 并集选择器建议一个元素占一行进行书写  
* 下面示例，将苹果、香蕉、鸭梨改为红色  
```css
div,
p,
ul>li {
    color: red;
}
```
```html
    <!-- 并集选择器 -->
    <div>苹果</div>
    <p>香蕉</p>
    <ul>
        <li>鸭梨</li>
    </ul>
```

4. 交集选择器  
* 和并集选择器对应，选择同时复合多个条件的元素  
* ``选择器1选择器2选择器3... {;}``  
* 两个元素必须紧紧挨在一起的  
* 注意：  
	1. 存在标签元素必须开头（和.以及#作为区分）  
	2. 不存在两个都是元素标签（比如p和span进行交集）  

* 示例  
```css
	p.a.c#d {
        color: red;
	}
```

5. 兄弟选择器  
	1. 选择紧紧相邻的兄弟元素  
	* ``兄弟元素1+兄弟元素2 {}``  
	* 只往下看，选择兄弟元素2设置样式  
	* 如果没有找到，则不设置任何样式  
	2. 选中第一个元素之后所有的对应兄弟元素  
	* ``兄弟元素1~兄弟元素2 {}``  
	* 选择兄弟元素1之后所有的兄弟元素2  

6. 属性选择器  
	1. 选择具有对应属性的元素  
	* ``[属性] {}``  
	* 选择[]内部的存在对应属性的标签  
	2. 选择具有对应属性值的元素  
	* ``[属性="属性值"] {}``  
	3. 选择具有对应属性并且以xx为开头的元素  
	* ``[属性^="xx"] {}``  
    4. 选择具有对应属性并且以xx为结尾的元素  
	* ``[属性$="xx"] {}``  
	5. 选择具有对应属性并且值存在xx的元素  
	* ``[属性*="xx"] {}``  
* 使用场景：筛选属性值的元素  

#### 伪类选择器  
* 所谓伪类选择器，其实就是**html结构经过用户的一些操作和输入存在和之前不同的状态**作为区分，从而产生了选择器，这样可以对其样式做出更好的区分（很像类，但不是类，是元素特殊状态的一种描述）  
* 一般上述的产生区别有点击链接、表单输入等情况  
##### 动态伪类  
* 动态的行为-动态伪类  
1. **链接伪类选择器**  
```css
a:link 选择未被访问过的链接
a:visited 选择已经被访问过的链接
a:hover 选择鼠标指针悬停上的链接（重点）
a:active 选择活动链接(鼠标按下了但是未弹起)
```

* 下面实现一个效果,鼠标悬停在链接上链接放大，鼠标按下链接，链接文字缩小，访问过链接后颜色变为绿色(让浏览器清除此网站的历史记录可恢复:ctrl+shift+del)  
* 顺序不可改变，理由就是一瞬间可能出现几种伪类情况的出现，由于覆盖问题，所以会出现问题  

```css
a {
    font-size: 30px;
    text-decoration: none; /*去掉下划线*/
}
/* 访问过的链接 */
a:visited {
    color: green;
}
/* 鼠标悬停到链接上 */
a:hover {
    font-size: 50px;
}
/* 鼠标按下但是没弹开 */
a:active {
    font-size: 10px;
}
```
```html
    <!-- 伪类选择器 -->
    <!-- a标签伪类选择 -->
    <a href="#">这是一个神奇的链接</a>
```

* 注意:  
> 按照 LVHA 的顺序书写, 例如把 active 拿到前面去, 就会导致 active 失效. 记忆规则 "绿化"
> 浏览器的 a 标签都有默认样式, 一般实际开发都需要单独制定样式.
> 实际开发主要给链接做一个样式, 然后给 hover 做一个样式即可. link, visited, active 用的不多.  
> link和visited是a标签的独有状态  

2. 其他选择器  
* ``元素:hover`` 表示此元素鼠标悬浮在上面的状态（通用）  
* ``元素:active``表示此元素鼠标按下不松开的状态（通用）  
* force主要表示焦点数据，**需要注意只能输入东西的元素才能使用-表单类元素**  
	* 比如可以设置表单中的input标签被选中时的内容状态  
	* 下面的例子可以让选中input标签内的内容变成红色  
```css
.select_>input:focus {
    color: red;
}
```
```html
    <!-- 焦点伪类选择 -->
    <div class="select_">
        <input type="text"><br/>
        <input type="text"><br/>
        <input type="text"><br/>
    </div>
```

##### 结构伪类  
###### 父元素中的子元素  
* 选择元素中的第一个儿子元素b``[元素a[>|' ']]元素b:first-child {}``  
	- 依据的其实是元素b的父元素元素a或者元素a的子辈或者任意父辈  
	- 理解为：**指定父元素元素a(或者元素a~元素b之间的辈分，或者是任意父辈(前提是元素a和b之间是后代选择器))中的第一个子元素并且是元素b**  
	- 注意下面的示例1:  
```html
<style>
	div>p:first-child {
        color: red;
	}
</style>
<body>
	<div>
		<span>1</span>
		<p>2</p>
		<p>3</p>
		<p>4</p>
	</div>
</body>
```

- 
	- 注意上面的例子没有任何一个数字设置为红色，理由就是first-child是基于div的子元素中的第一个，然后此时又要选择p，不存在所以没有设置  
	- 如下示例2，说明后代选择器或者不设置父辈，应该遵循的结构选择规则：  
	- 情况1  
```html
<style>
	div p:first-child {
        color: red;
	}
</style>
<body>
	<p>7</p>
	<div>
		<p>6</p>
		<a href="#">
			<p>5</p>
			<p>1</p>
		</a>
		<p>2</p>
		<p>3</p>
		<p>4</p>
	</div>
</body>
```

- 
	- 此情况下，6和5会被显示红色，因为首先大前提必须是div的后辈（后代选择器），其次在div的第一个子元素正是p元素，所以6显示，其次a元素（div的后辈，p的前辈）的第一个子元素也是p元素，所以5显示  
	- 情况2  
```html
<style>
	p:first-child {
        color: red;
	}
</style>
<body>
	<p>7</p>
	<div>
		<p>6</p>
		<a href="#">
			<p>5</p>
			<p>1</p>
		</a>
		<p>2</p>
		<p>3</p>
		<p>4</p>
	</div>
</body>
```

- 
	- 可以发现，此时应该是7、6、5被显示成红色，因为此时没有限制是谁的子辈，那么在任意父亲下的第一个子元素只要是p即可  

* 选择最后一个子元素 ``元素:last-child {}``  同理，也是按照所有子元素进行计算的，类似与上面的状态，只是变成最后一个而已  
* 选择第n个子元素 ``元素:nth-child(n) {}`` 同理，只是按照1开始的顺序进行选择即可  
	- 不写或者0的话谁也不会选择  
	- 范围按理来说（0~∞），但是超出范围或者不存在对应下标都不会发生选择  
	- 如果设置为n，会选择全部（但是这样就不需要伪类选择器了）  
	- 另外，里面可以写入公式，比如2n（even）就表示挑选偶数的下标进行选择，2n-1(odd)表示挑选奇数。  
		- 复杂需求1：比如要前五个: -n+5   
		- 
	- 总结，实际上公式就是围绕着n进行，n是一个从0~正无穷变化的数，将其控制到可选范围内即可，**另外格式需要控制在an+b的格式（n必须在前面）**  

* 选择父辈唯一的孩子``元素a:only-child {}``表示存在一个父辈，存在一个唯一的儿子，并且是元素a，即可选择  

###### 相同元素-同类型子元素  
* ``元素:first-of-type {}``表示和元素相同的第一个元素  
* ``元素:last-of-type {}``表示和元素相同类型的最后一个元素  
* ``元素:nth-of-type(n) {}``表示和元素同类型的第n个元素，公式类似与上面的方式  
* ``元素:nth-last-of-type(n) {}``表示和相同元素同类型的倒数第n个元素  
* ``元素:only-of-type {}``表示只有一个相同类型的兄弟（和child的兄弟对比）  

###### root  
* ``:root {}`` 选中的是根标签-html，此时可以设置整体结构(类似于``*``)  

###### empty  
* ``元素:empty {}``选中的是对应元素中是空（即什么都没写）的标签  
* 空格也算内容  

##### 否定伪类  
* ``元素:not() {}``括号内写入需要排除的选择器即可  
* 选择器任意即可  

##### UI伪类  
* 存在一些坑，比如input中的checkbox复选框，我们想实现一个效果，就是选上放大，否则变小。如果利用之前动态伪类的知识，会想到焦点：focus，但是对于**复选框而言，只要选上了就始终是获取焦点**，会出现问题  
* 可以利用checked解决此问题，表示是否选中，勾选上才会进行选择（复选框和单选框），实现效果``input:checked {}``  
	- 扩展：复选框和单选框的样式是改变不了的（比如颜色），实际UI设计中，可以利用JS技术，将本来的选框隐藏，只提供功能，然后前端设计比如div配合js设置点击事件，值传递给隐藏的选框组件，这样可以实现更改样式但是功能还在的效果  

* ``input:disabled {}`` 选择表单中被禁用的表单元素  
* ``input:enabled {}`` 选择表单中没有禁用的表单元素（用的很少）  

##### 目标伪类  
* ``元素:target {}`` 通常在描点中，跳转到对应元素会进行选择（理解为选中元素并且#id即可）  

##### 语言伪类  
* 需求选择语言（感觉属性选择器也能做），``[元素]:lang(语言) {}``即选中元素中语言设置为对应语言的标签，当然元素也可以省略，这样全部标签中存在对应语言即可  

#### 伪元素选择器  
* **伪元素：很像元素，但不是元素，是元素中的一些特殊位置。**（类比于伪类）  
* vscode：lorem可以生成一串文字，后面跟上数字可以指定生成几个单词  
* 示例场景：在一串文本中控制其中的某个单词的样式  
* 语法格式:``::`` 表示伪元素，一个表示伪类  
1. ``元素::first-letter {}``letter文字-字母，表示元素中第一个字母的样式  
2. ``元素::first-line {}`` 表示元素中选择第一行（根据浏览器中显示元素的大小展示第一行）  
3. ``元素::selection {}``表示鼠标选中的文字，选择设置样式  
4. ``input::placeholder {}``表示输入中的提示文字，选择设置样式  
5. ``元素::before {}`` 表示指定元素内容之前的位置。样式通过``content: "内容"``可以对其内容进行设置，**after**可以设置之后，并且样式内设置的内容显示在网页上，用户不可选中，实际上就是在指定元素中插入子元素  
6. ``input::-webkit-input-placeholder`` 可以对提示文本设置样式  

### 选择器优先级  
* 当我们通过**不同的选择器**选择**相同的元素**，并且为**相同的样式值**，**设置不同的值**，此时就会产生样式的冲突，此时就需要看优先级了  
1. 单选择器下的优先级：  
	* 行内(不属于选择器) > ID选择器 > 类选择器 > 元素选择器 > 通配选择器  

2. 复合选择器下的优先级：  
* 当存在多个选择器选择相同的元素并且设置了相同的样式值，此时需要抉择谁的权重大  
* 如何计算权重？  
	- 格式(a,b,c)  
		1. a:ID选择器的个数  
		2. b:类、伪类、属性选择器的个数  
		3. c:元素、伪元素选择器的个数  
* 如何比较权重？  
	- a和a比较，b和b比较，c和c比较。  
	- 从左往右比较，一旦存在一方大，结束战局，大的那方就是权重大的  
	- 如果权重相等，此时就是后来者可以覆盖了  

* 实际上上述两种比较方式均是运用权重来进行比较的。可以看到，ID权重最大，其次类、伪类、属性，再其次元素、伪元素  
* 实际上再vscode上是可以帮你计算的权重的。实际开发中可以利用其查找权重一致，查bug的  
* 行内权重最高，但是在元素样式内属性值的后面添加：``元素 { 属性: 值 !important}``表明此值为重要的，此时就会比行内的优先级最高（慎用，特殊场景：解决bug-速度快速改-能跑就行）  

## CSS的三大特性  
1. 层叠性  
* 如果发生了样式冲突，就会根据一定的规则(选择器优先级)，进行了样式的层叠 （覆盖）  
2. 继承性  
* 元素会自动拥有其父元素或者其祖先元素上的某些样式  
* 规则，优先继承最近的  
* 能继承的属性：  
	- 查看文档：是否是继承属性即可  
	- ``text-? font-? line-? color ......``  
3. 优先级  
* 计算权重详细计算即可：!important>行内样式>ID选择器>类选择器>元素选择器>通配符选择器>继承的样式  
* 注意并集选择器，每个元素都是分开来算的（不是一起的，即相当于每个元素分开写，即几个元素选择器）

### 字体属性  
1. 设置字体  
```css
{
    font-family: 'Microsoft YaHei';
}
```

* 字体名称可以用中文, 但是不建议（存在兼容性问题）  
* 多个字体之间使用逗号分隔. (从左到右查找字体, 如果都找不到, 会使用默认字体. )  
* 如果字体名有空格, 使用引号包裹.  
* 建议使用常见字体, 否则兼容性不好.  
* 寻找的是电脑本地中的字体  
> 注意：字体分为衬线字体（毛笔，书法感）、非衬线字体。区分：没有顿挫感  
> 网页中非衬线字体居多（需要注意想要写的字体族，需要都是一种类型的字体）  
> 上述情况下，针对同一种字体，最后结尾可以加上sans-serif表明拿一个非衬线字体使用（衬线：serif）  
> windows中默认的字体就是微软雅黑  

2. 设置字体大小  
```css
{
    font-size: 20px;
}
```

* 不同的浏览器默认字号不一样, 最好给一个明确值. (chrome 默认是 16px)  
* 可以给 body 标签使用 font-size  
* 要注意单位 px 不要忘记.  
> 注意: 实际上它设置的是字体中字符框的高度；实际的字符字形可能比这些框高或矮  
> chrome浏览器接受的最小大小为12px（不同的浏览器初始设置不同-浏览器设置可改），小于12px除开0都会设置为12px（0会直接消失）  

* 实际上，对于font-size，是指定的字体所在的框（高度一致，宽度按照比例进行变化）。  
	- 字体框设计时会通过适应所有字体做出一些调整，不是处于最中间的，可能会向下或者向上偏移一点，宽度进行自适应  
	- 字体的设计是允许超出字体框一点点的（比如微软雅黑）  
	- 字体中（小写字母x的最下面的平切线）存在基线。（字母也是可能会超过基线的，比如(x)g... - 微软雅黑里）  
* 综上，由于字体设计的原因，文字最终呈现的大小，并不一定与font-size的值一致，可能大，也可能小。通常情况下，文字相对于字体设计狂，并不是垂直居中的，通常都是靠下一点点  

3. 设置字体粗细  
```css
{
    font-weight: 666;
}
```

* 字体粗细的取值范围是[100, 1000]  
* 存在一些常用的粗细值表示：bolder bold==600（>=600）， normal=400（400~500）// 不变粗  lighter=100（100~300）细  
* 需要注意有些字体就只设计了三种效果（比如微软雅黑），那么数值也就不会那么精细  

4. 设置字体风格  
```css
{
	/* 设置倾斜 */
    font-style: italic;
    /* 取消倾斜 */
    font-style: normal;
}
```

* normal，正常的，通常的。默认值  
* italic，斜体（优先找字体设计者设计的斜体，否则强斜）  
* oblique，斜体（找到正常设置的斜体，强制进行斜）  

5. 字体复合属性  
* 字体大小、字体族必须带，并且处于最后的位置  
```css
{
    font: [bold] [italic] 100px "Microsoft YaHei"[, "STHupo"...];
}
```
* 多个属性进行设置推荐复合写法写  

### 文本属性  
<a href="#" name="yanse"></a>
1. 文本颜色  
```css
{
    color: blue;
}
```

* 颜色的表示有三种写法，均是以RGB格式进行书写  
	1. 预定义的颜色值(单词表示)  
	2. HEX/HEXA``#FFFFFF``(16进制值，两个表示RGB的其中一个值，因为(0~255-1byte=8bit=2位的16进制数))  
		- 另外对于16进制的表示方式，比如:``#ff00ff => #f0f`` 如果两者相同可以直接用1个进行  
		- 同样的，最后两位可以增加一个00~ff表示透明度，同样的如果简写也可以进行简写  
		- 需要注意透明度IE浏览器不支持  
	3. ``RGB(255, 0, 0)``RGB中写10进制的方式  
		- 另外还有``rgba(255, 0, 0, 0.5)``可以控制透明度，透明度的取值是0~1(不设置透明度默认为1完全不透明)  
	4. 了解一下，使用的不多-HSL/HSLA  
		- ``color: hsl(色相, 饱和度, 亮度);``  
		- 色相：角度进行表示（在色相环中，0°红色，120°绿色，240°蓝色），其中°用deg代替（也可以省略）  
		- 饱和度：0%~100%，颜色浓郁可越大（0%->纯灰色）  
		- 亮度：0%~100%，0相当于关灯(黑)，100%相当于全开（白） 
		- 也支持透明度，在后面加个a->``hsla(30, 100%, 50%, 0.5)``   
	* 颜色规律：255、255、255全打满，颜色最亮-白色，0、0、0没有光，黑色，值相同的时候显示灰色，越低越暗，越高越浅-白  

2. 文本对齐  
> 控制文字水平方向的对齐  
> 不光能控制文本对齐, 也能控制图片等元素居中或者靠右  
```css
{
    text-align: center;
}
```

* center居中，left左对齐，right右对齐  
* 注意需要在以**行**为单位的标签内方可生效

```css
{
    text-decoration: underline;
}
```

* 常用的取值	:  
	1. underline 下划线.  
	2. none 啥都没有. 可以给 a 标签去掉下划线.  
	3. overline 上划线.  
	4. line-through 删除线  
* 除了设置修饰，还能给线设置样式：（直接在属性值后面进行添加即可）  
	1. dotted-虚线  
	2. wavy-波浪线  
	3. red-设置颜色（需要加载后面）
	4. 顺序没有需求  
```css

    font-decoration: underline wavy #ffff;

```

4. 文本缩进  
```css
{
    text-indent: [值];
}
```

* 值的单位可以使用px或者em  
* 使用 em 作为单位更好. 1 个 em 就是当前元素的文字大小.  
* 缩进可以是负的, 表示往左缩进. (会导致文字就冒出去了)  
* 注意类似于文本缩进，需要再以**行为单位**的标签内才能生效  

5. 行高  
* 首先明确在html中文字的表示行高：**上下边距 + 字体大小**  
```css
{
    line-height: [值];
}
```

* 1值使用px进行表示即可  
* 选中文本可以确认行高  
> 注意，根据字体设计，一旦行高和字体大小高度一致（具体看字体），可能存在上下两行字体重叠的问题（本身字体可能会超出font-size设置的字体框）  

* 2默认不写，相当于值为normal（浏览器决定给个合适的行高）  
* 3如果写数值1：表示是字体大小的1倍，一般给的规则：就是行高一般为字体大小的1.5~2倍之间（用的比较多）  
* 4可以写百分比，也是相对于字体大小进行的  

* 注意特殊情况解释其属性：
	1. 当行高设置为0  
	> 1. 字体重叠在了一起（垂直间距为0了）  
	> 2. 背景色不见了（因为此时行高设置为0，那么height就为0）  
	> 3. 上面被吞掉了一点（因为此时行高为0，字体框还是大概存在中部一部分，只不过此时中间这条线变成了上边框罢了）  

	2. 行高是可以继承的，并且一行中如果存在设置的不同行高（不是覆盖-不是冲突，即不同元素设置在相同一行但是不同行高），会设置为最高的行高。字体之间的对齐，默认**基线对齐**  
	3. line-height和height之间的关系：存在height，那么此标签高度就是height的值，如果没有设置，那么height就是``line-height*行数``的值  

* 行高的应用场景：  
	1. 调整多行文字的间距  
	2. 单行文字的垂直居中（将行高和height一致即可）  
	3. 也可以控制文本对齐的垂直方向下（可以将行高设置为高度的的两倍在减去字体大小值，这样能设置一个下面的位置（可以再减去一个值），但是并不推荐，后续推荐使用定位去做）

### 背景属性

```css
    border-bottom-left-radius: ;
    border-bottom-right-radius: ;
```

* 也可以依次写：左上角、右上角、右下角、左下角(顺时针的顺序)依次指定圆角的半径

### 元素显示模式  
1. 块元素(block)  
* 块级元素在页面独占一行，不会和任何元素共用一行，是从上到下排列的  
* 默认宽度：撑满父元素（浏览器会默认给body增加一些样式导致撑不满，将外边距margin设置为0即可）  
* 默认高度：由内容撑开  
* 可以通过css 设置宽高  

* 总结常见的块级元素：  
> 1. 主体结构标签：html、body  
> 2. 排版标签：h、hr(分割线)、p(段落)、pre(原文件排版)、div(无语义块级元素)  
> 3. 列表标签：ul、ol、li、dl、dt、dd  
> 4. 表格相关标签：table、tbody、thread、tfoot(尾)、tr、caption(标题)  
> 5. 表单form和select（不是块级元素）选框中的option  

2. 行内元素(inline)  
* 内联元素。在页面中不独占一行，一行中不能容纳下的行内元素，会在下一行继续从左到右排列  
* 默认宽度、高度：由内容撑开  
* **无法通过css设置宽高**  

* 总结常见的行内元素  
> 1. 文本相关：br（换行）、em（呈现字体图标）、strong（关键字）、sup（上标元素）、sub（下标元素）、del（删除内容）、ins（与正常的文本有反差的文本，比如插入文本）  
> 2. 超链接a标签和提升用户体验的label标签  

3. 行内块元素(inline-block)  
* 内联块元素  。在页面中不独占一行，一行中不能容纳下的行内元素，会在下一行继续从左到右排列  
* 默认宽度、高度：由内容撑开  
* **可以通过css设置宽高**  
* 代表：``<img scr="">``  

* 早期分类行内和块级元素，依据是否独占一行进行区分  
* 总结常见的行内块元素  
> 1. 图片：img  
> 2. 单元格：th（首行）、td（普通单元格）  
> 3. 表单控件：input、textarea（文本框）、select（选框）、button（按钮）  
> 4. 框架标签：iframe  

* 默认宽度：就是不设置width属性时，元素呈现的宽度。  
* 总宽度：父的content - 自身左右的margin  
* 内容区的宽度：父的content - 自身左右的margin - 自身左右的border - 自身左右的padding  

#### 修改元素的显示模式  
* display属性可以控制元素的显示模式  
	1. 块：block  
	2. 行内：inline  
	3. 行内块：inline-block  
	4. none：不进行显示

### 盒子模型的组成部分  
* 每一个HTML元素相当于是一个矩形的盒子，这个盒子由下面的几个部分组成  
1. 边框 border  
2. 内容区 content（默认写宽和高就是内容的宽和高）  
3. 内边距（补白） padding  
4. 外边距 margin  

#### 盒子内容content  
* 除开width、height控制宽度和高度，还有：  
	1. min-width：设置最小的宽度（浏览器窗口中最小不能低于其）  
	2. max-width：设置最大的宽度（不能大于，浏览器设置的存在底线-即视口的最小值）  
	3. min-height、max-height同理  

#### 边框border  
* 基础属性  
1. 粗细：border-width  
2. 样式：border-style(默认没边框，solid实线边框 dashed虚线边框 dotted点线边框)  
3. 颜色：border-color  
4. 基础属性可以直接用border: 进行描述(先后顺序并没有规定)  
* 让border不把盒子给撑大（即宽度和高度和设置的一致）``box-sizing: border-box``  
* 实际上背景属性也会对边框进行填充  
* 同样可以针对上右下左进行设置border（border-right-color）  

#### 内边距padding  
* 背景属性也会对内边距进行填充  
* 针对四个方向进行设置：padding-left、top、right、bottom  
* 复合写法：padding：[top right bottom left]...  
	- 注意，1个表示四个方位均是此值，2个前面表示上下，后面表示左右，3个第一个表示上，第二个表示左右，第三个表示下；4个表示从顺时针开始表示：上、右、下、左  
* 行内元素可以设置内边距，但是注意上下如果设置可能会产生重叠（块不会出现问题）  
* 不让内边距对盒子撑大（即宽度和高度和设置的一致）``box-sizing: border-box``  

#### 外边距margin  
* 不会影响盒子的大小  
* 用于控制盒子和盒子之间的距离  
* 四个方向同内边距，写法一致，只不过用margin替换padding即可  
* ``margin: auto;``可以设置对应盒模型（块级元素）进行一个居中显示  
* 方向上也可以设置为auto，此auto具体值取决于浏览器，适用于浏览器中的自适应  

* 注意事项  
	1. 子元素的margin是参考父元素的content计算的  
	2. 上和左设置会影响自身的位置，下和右会影响兄弟元素的位置  
	3. 行内元素上下margin无法进行设置  
	4. margin的值可以给一个块级元素左右设置auto实现该元素在父级元素内进行一个水平居中  
	5. 可以设置负值，下面的可以覆盖上面的标签  

##### margin塌陷问题  
* 发现问题1：在默认情况下，第一个子块级元素存在在父元素的左上角，当给其设置margin-top，发现时父级元素跟着一起动了，而不是父级元素内上面存在留白  
* 发现问题2：最后一个子块级元素设置margin-bottom，被父级元素设置了，父级内容中没有进行呈现  
* 解决方案：  
	1. 给父级设置border  
	2. 给父级设置一个内边距  
	3. overflow：hidden（不影响父级盒子大小的情况下解决塌陷问题）  
		- overflow即溢出之后的显示模式，hodden表示隐藏  
* 出现原因：早期设计原因（给第一个和最后一个子元素设置margin-top和bottom给父级元素是一个比较好的行为）。  

##### marigin合并问题  
* 发现问题：给一个相邻的块级元素一个设置margin-bottom一个设置margint-top相同值，会发现间隔并不是期望的值的二倍（不同值能够合并的地方同理，总之不会直接相加），而是相同值（合并共用）  
* 只出现在上下的设置情况  
* 可以不需要解决，解决的话可能会产生副作用（比如设置float：left...）  

### 处理内容的溢出  
* 谁是容器，给哪个加上属性  
* overflow - 处理溢出的属性  
	1. hidden：横向和纵向上，只要超出内容区一律隐藏  
	2. visible：默认值，就是显示  
	3. scroll：会给容器增加滚动条  
	4. auto：自动，如果超出的话会增加滚动条  
* overflow-x控制横向上的溢出、overflow-y控制纵向上的溢出  
	- 注意，不允许出现visible和hidden同时设置  
	- 这两个属性是实验性的功能（以后可能出现改动）  
	- 不建议去使用  
* overflow除了控制溢出内容，还能解决各种疑难杂症  

### 隐藏元素的方式  
1. display：none  
2. visibility：hidden  
	- 默认show显示  
	- 此处隐藏还会进行占位  

### 样式的继承  
* 能继承的属性：字体属性、文本属性（除开vertical-align）、文字颜色等  
* 不会继承的css属性：边框、背景、内边距、外边距、宽高、溢出方式等  
* 规律：能继承的属性都是不会影响布局的（即和盒子模型不相关的属性）  

### 元素的默认样式  
* 一般存在默认样式：a标签、h、p、ul、body  
* body默认样式（margin：8px）  
* 需要注意继承的样式优先级是最低的  

### 布局技巧  
* 行内元素和行内块元素，都可以像调整text进行调整  
* 设置行内元素居中，可以根据vertical-align设置与其他行内元素进行垂直居中。如果想设置**绝对的垂直居中**，需要注意，如果是文本，那么会存在设计的问题导致不会那么居中，由于可以控制文本大小（行内元素的父级元素），设置极端的0px就可以保证，另外的非文本元素绝对的竖直方向上的垂直对齐（需要设置vertical-align：middle）  
	- 消除父元素内文字对子元素的影响：（父元素内设置文字大小为0px）  
```html
<!DOCTYPE html>
<html lang="zh-CN">
    <head>
        <meta charset="utf-8">
        <title>测试样式</title>
        <style>
            .f1 {
                width: 400px;
                height: 400px;
                background-color: gray;
                text-align: center;  /* 行内和行内块元素均可以当作文本处理 */
                line-height: 400px;  /* 同上 */
                font-size: 0px;  /* 依据此，竖直方向上进行垂直居中 */
            }
            .f2 {
                vertical-align: middle;  /* 垂直居中对齐其他行内元素 */ 
                background-color: orange;
            }
            .f3 {
                height: 150px;  /* 图片为行内块元素别忘了 */
                vertical-align: middle;
            }
        </style>
    </head>
    <body>
        <div class="f1">
            <span class="f2">出来玩呀？</span><img class="f3" src="./img/水美游.jpg" alt="水美游">
        </div>
    </body>
</html>
```

### 元素之间的空白问题  
* 面对行内（包括行内块）元素时，存在回车以及空格会存在解析为一个空格布局的情况，那么如何消除空格的影响呢？  
* 解决方法：  
	1. 不换行（观感不佳）  
	2. 实际上空格也是文字，可以给其父元素设置fs为0即可（存在问题：其他文字元素也会受到影响，需要单独设置）  

### 行内块的幽灵空白问题  
* 在块元素中的行内块中，如果不设置块元素height（随内容变化），内部存在一个行内块元素，那么其下面会多出来一块空隙，称作幽灵空白  

  - 实际上，就是行内元素之间的基线对齐，也是文本格式的弊端，和之前的图片垂直对齐类似  
* 解决：
	1. vertical-align: top;  
	2. vertical-align: center;  
	3. vertical-align: bottom;  
	- 不为baseline基线即可  
	4. display: block;(弊端：兄弟元素不存在其他的东西)  
	5. 由字造成的问题，可以给其父元素设置fs为0即可  

## 浮动  
* 早期设计是为了文字环绕图片，现在大多可以用作布局  
* 浮动的属性：float（行内元素不会按照基线进行对齐，其他会环绕着它）  
	- left 左浮动  
	- right 右浮动  

### 布局发展  
1. 表格布局：（网站复杂，难以维护）  
2. 浮动布局：（布局不错）  
3. 弹性布局：（css3）  

### 元素浮动后的特点  
* 一个元素浮动之后（不管你是什么元素（块、行内）），均遵循浮动元素特点  
1. 元素浮动后，脱离<em>文档流</em>的  
	- 文档流：元素默认的样式（行内、块元素的特点）  
2. 元素浮动后，宽与高默认情况下都是由内容撑开，可以设置宽高  
3. 浮动后可以与其他元素共用一行（实际上可以升一维，理解为浮动了）  
4. 浮动之后的元素，margin、padding四个方向均可以完美设置，且不会存在margin合并和margin塌陷问题  
5. 浮动之后的元素，不会像行内元素一样，当作文本处理（也就不会存在行内块的下方空白问题）

### 浮动后的影响  
1. 父元素塌陷，进而产生很多的副作用（父元素的宽度依然可以束缚浮动元素）  
2. 对后面的兄弟元素存在影响（前面的兄弟元素不会存在影响）  
	- 如果后面元素为inline-block，那么可以和浮动元素共占一行或者下面去，不会出现和块元素在浮动元素下面的问题  


* 解决影响：  
1. 计算父元素的宽度，设置height属性即可（能解决父元素塌陷问题，不能解决对兄弟块元素的影响 ）  
2. 父元素设置float: left。（能解决父元素塌陷问题，不能解决对兄弟块元素的影响，并且父亲的之前的兄弟元素 也会受到影响）  
3. overflow: hidden（能解决父元素塌陷问题，但是会把受影响的兄弟元素给隐藏了）  
4. 给受到影响的兄弟元素设置属性：clear: left;(消除掉当前前面所有左浮动兄弟产生的影响)，同理，right是右，both是所有方向（此时可以完美解决）  
	- 注意，如果设置clear属性设置为float浮动，那么此时就无法解决父元素塌陷，并且忽视掉前面兄弟的浮动影响（即就是本来的位置）  
	- clear属性不可给行内元素inline增加（没有影响）  
	- 解决方案：设置一个空的div，给其设置clear元素，消除前面兄弟元素浮动的影响，让父元素不会塌陷，并且不影响后面的兄弟元素  
5. 使用伪元素增加最后一个内容，并且设置block（默认inline），并且用于消除前面兄弟元素的浮动元素的影响：  
```css
.outer::after {
    content: '';
    display: block;
    clear: both;
}
```

- 注意，此种方案前面不能出现不浮动的元素，否则出问题了  
- 浮动布局原则：一个父元素内，子元素要么全飘，要么都不飘（此时之前的方案都有效）  

### 浮动布局练习  
* 题目如下：  
![浮动布局练习设计稿](./浮动布局练习.png)

* 编写技巧：  
> css中一些通用的属性写一次（比如浮动和清除浮动），设置一个类，这样可以确定写了多少次属性，复用性低  
> 相同的属性多使用并集选择器  

* 编写思路：  
1. 将所有的内容装进一个大容器内（设计时，高可以由内容撑开，宽需要进行设置），一般大容器需要进行一个水平居中，可以对文本设置center  
2. 第1个子容器头部page-header: 设置浮动，父元素清除浮动，宽高，设置居中，间隔   
3. 第2个子容器菜单menu，设置居中，上边距  
4. 第3个子容器内容content，左侧，右侧处于同一行，需要进行浮动  
	- 左侧：top（内部两个元素浮动，并且父元素清除浮动）、bottom（同理）  
	- 右侧：此时直接块元素即可  
5. 第4个子容器footer

```html
        /* 整体页面居中 */
        .page {

            text-align: center;
        }

        /* 网页头部 */
        .logo,.banner1,.banner2 {
            width: 200px;
            height: 80px;
            background-color: #CCC;
            line-height: 78px;
        }
        .banner1 {
            width: 540px;
            margin: 0 10px;
        }

        /* 网页菜单 */
        .page-menu {
            width: 100%;
            height: 30px;
```

## 定位  
* css中的定位：把一个元素精准的摆在一个位置  
* 给元素开启了定位，层级是比普通元素要高（覆盖），如果都存在定位，后写的盖在前面的身上  
* 定位可以超出父容器的范围（对比学习：浮动中不行）  
* 注意定位left和right、top和bottom不能同时使用，同时使用left、top生效  
* 定位可以与margin配合，但是不推荐  
### 相对定位  
* 开启相对定位：``position: relative;``(相对)  
* 指定位置：``left: 100px``(**相对于**左边left、右边right、上面top、下面bottom离的距离)  
* 相对于：设置相对位置**之前**的位置（原来的位置）  
* 开启了相对定位的元素并没有**脱离文档流**（块级元素独占一行...）  
* 相对定位可以和浮动配合，但是不推荐  
* 应用场景：  
	1. 微调  
	2. 相对定位和绝对定位进行配合（大多数情况下）  

### 绝对定位  
* 开启绝对定位：``position: absolute;``(绝对的)  
* 开启了绝对定位，**脱离了文档流**，和浮动效果不同，文字不会进行环绕（复合常识认知） 
* 同理，存在left、right、top、bottom设置距离位置，但是此时的参考点：**包含块**   
	- 包含块：1. 没有脱离文档流的元素，父元素就是其包含块 2.脱离文档流的元素，第一个开启**定位**的祖先元素，就是他的包含块   
* 为什么绝对定位和相对定位进行配合？  
	- 相对定位不会影响文档流（对其影响最小），其子元素设置绝对定位，此时子元素可以随意设置相对于父元素的位置  
* 注意在绝对定位中，你设置的什么方位（left、right、top、bottom），margin才能设置对应的  
* 绝对定位和浮动不可共存，如果冲突则选择绝对定位  
* 文档流中的无论什么元素，开启绝对定位，变成了**定位元素**  
	- 宽与高默认被内容撑开  
	- 宽与高可以设置  
* 应用场景：  
	- 一个元素盖在另一个元素的身上  
	- 对浮动布局的一个辅助（性能+浏览器的适应）  
```HTML
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>绝对定位练习</title>
    <style>
        * {
            margin: 0;
            padding: 0;
        }
        
        /* 开启相对定位 */
        .pos_relative {
            position: relative;   
        }

        .outer {
            width: 800px;
            padding: 20px;
            background-color: skyblue;
            border: 1px solid black;
        }

        .box {
            width: 150px;
            height: 270px;

            position: absolute;
            background-color: orange;
            top: 20px;
        }

            width: 150px;
        }

        /* 动态伪类 */
        .outer:hover .box {
            left: 170px;
        }


    </style>
```

### 固定定位  
* 开启固定定位：``position: fixed;``(固定)  
* 同样的脱离文档流，并且参考点为视口（固定不变-视口）  
* 和其他定位不同，它的参考点**绝对**的固定视口（随着内容变化，位置固定不变） 
* 其余类似与绝对定位属性，同样的也是定位元素   

### 粘性定位  
* 用下面的例子进行解释：类似于特定时机粘住某个元素，并且不是一直沾着的  
* ``position: sticky;``设置粘性定位  
	- left、right、top、right设置粘性生效区域  
	- top: 10px;表示**参考离本元素最近的一个拥有滚动的祖先元素**，一般就是body具有滚动行为，即离其上方存在10px距离时，定位生效，直到其本身父元素结束收走时失效  
	- **也可能是不存在滑块（即参考的是overflow:scroll）**,会对其进行参考，但是此时一般就不会进行生效了  
* 常用的值 top：0px;  
* 不脱离文档流，是一种新的定位方式  
* 可以和浮动进行配合，但是不推荐

### 定位的层级  
* 首先无论是什么定位，它们的层级都是一致的  
* 层级一致，在html的结构中谁靠后，谁的层级就大（覆盖）  
* 存在属性``z-index``可以调整定位元素的层级（z-index越大，层级越大。默认值：auto即0）  
* 注意，不单单是z-index起作用，还有包含块（拥有定位的祖先元素）中z-index的影响  

### 定位的特殊应用  
* 首先绝对定位的参照父元素时，会越过padding  
* 下面针对于**定位元素**（绝对定位、固定定位）的应用场景  

1. 存在这样的特殊的场景：一个盒子设置了padding以及border，现在想让其整个充满父容器的宽。此时假设父容器宽是视图的大小就没法设置，可以利用绝对元素（父为相对元素），设置left:0,right:0即可解决问题。高度同理（top:0, bottom:0）  

  - 绝对定位元素、没宽高、充满整个父元素  
2. 当想设置垂直水平居中，可以利用定位去做：同理使用绝对定位和相对定位配合  
	- 1.top、bottom、left、right均为0，margin为auto，注意缺一不可（推荐）  
	- 2.left：50%，top: 50%,margin-left:- 宽度的一半，margin-top：-高度的一半  
	* 前提：设置的定位元素必须要设置宽高

## 布局  
### 版心  
* 布局网页的时候，高度由内容撑开，一般需要考虑宽度，用于适应不同分辨率的显示屏  
* 首先是外面的格子宽度不给->屏幕打满宽度，内部嵌套一个盒子（居中？），高度不给，宽度给个960~1200px之间（时效性）  
* 嵌套的盒子就被称作版心。空下的空隙可以设计留白或者其他之类的  
* **无论分辨率即电脑屏幕多大，都可以将网站的主体内容在中央显示，这就是版心的意义**  
* 可能存在多个版心，即分块版心（比如：上中下-推荐）  
* 版心默认的名词：container  
* 扩展：  
> 现在存在响应式，可以弱化版心的概念，它可以根据分辨率自动调整网站的布局  

### 布局类名的单词  
1. 顶部导航条：topbar（一般第一行）  
2. 页头：header、page-header（头部，比如搜索框所在的位置）  
3. 导航：nav、navgator、navbar（导航跳转页）  
4. 搜索框：search、search-box、search-form  
5. 横幅、广告、宣传图：banner  
6. 主要内容：content、main  
7. 侧边栏：aside、sidebar  
8. 页脚：footer、page-footer  
9. 版心：container  

### 重置默认样式  
* 一些元素存在一些默认样式。早期是为了快速的绘制网页，但是现在网页的设计越来越复杂，默认的样式会给网页的设计带来麻烦  
1. 方案1：使用全局选择器  
```html
* {
    margin: 0;
    padding: 0;
    ......
}
```

* 简单案例可以使用，但是实际开发并不会使用，因为并不是所有的元素都有默认样式，并且有时候需要特定处理的  
2. 方案2：reset.css（主流）  
* 选择到具有默认样式的元素，清空其默认的样式  
* 经过reset后的网页，好似一张白纸，开发人员可根据设计稿，精细的去添加具体的样式  

3. 方案3：Normalize.css  
* 新的解决方案，在清除默认样式的基础上，保留一些有价值的默认样式  
* 标准化规定的东西（<a href="https://necolas.github.io/normalize.css/">链接</a>）  
* 为大部分HTML元素提供一般化的样式  
* 新增对HTML5元素的设置  
* 对并集选择器的使用比较谨慎，有效避免调试工具杂乱  

### 弹性布局  
* 前端为了实现一个布局效果采用的一种技术手段  
#### flex设置子元素弹性布局模式  
* 由于行内元素会随着内容进行改变，那么我们可以**使其直接父级元素**使用css属性：``display: flex``,这样就不会受内容进行改变了，但还是行内元素(不是独立成行的)  
* 需要注意，使用上述属性，表示所有的子元素变成弹性布局模式，可以展示出我们预期的展示效果  
#### 弹性布局横轴纵轴设置  
* 设置子元素的布局方式  
* justify-content:  横轴设置  
	1. start(默认)  
	2. centor  
	3. right  
	4. space-between 均匀排布  
* align-items：纵轴设置  
	1. start(默认)  
	2. center  
	3. end

## css3新增长度单位  
* vw单位：所占视口宽度的百分比（不需要写%,比如50vw）  
	- 应用场景：跟随视口进行变化的（大变大，小变小），移动端常用  
* vh单位：所占视口高度的百分比  
* vmax单位：视口宽和高最大的的百分比（比如视口宽大那就是宽作为基准）  
* vmin单位：视口宽和高最小的百分比  
* 长度计算：calc() 此时可以在calc内进行一个长度单位的数值计算(注意之间的空格)  

## css3新增盒子模型相关属性  
### box-sizing怪异盒子  
* content-box;(默认)-内容盒子，表示宽与高控制的是内容  
	- 保持内容区域  
* border-box;表示整个盒子的总宽高  
	- 压缩内容区域  

### resize改变大小  
* 前提：需要存在overflow属性（hidden、auto）  
* horizontal，水平方向上大小可以调整  
* vertical，垂直方向上大小可以调整  
* both，水平和垂直方向上都可以调整  
* none默认，不允许调整大小  

### box-shadow盒子阴影  
* 开发中使用比较广泛  
1. 第一种情况：写两个值  
	- box-shadow: 10px 10px;  
	- 水平方向的阴影 竖直方向的阴影  
2. 第二种情况：写三个值  
	- box-shadow: 10px 10px blue;  
	- 存在设置阴影颜色  
3. 第三种情况：写三个值  
	- box-shadow: 10px 10px 10px;  
	- 第三个值设置阴影的模糊效果，值越大越柔和  
4. 第四种情况：写四个值（比较多）  
	- box-shadow: 10px 10px 10px blue;  
	- 模糊程度 + 阴影颜色  
5. 第五种情况：写五个值  
	- box-shadow: 10px 10px 10px 0  blue;  
	- 在模糊程度和颜色之间增加数值，表示调整阴影的外延  
6. 第六种情况：写六个值  
	- box-shadow: 10px 10px 10px 10px  blue inset ;  
	- inset表示内阴影，默认阴影就是外面的  
	- 内阴影实际上挤外面的内容  

* 实际应用：提升用户ui交互体验  
* ``box-shadow:  h-shadow v-shadow [模糊] [外延] [颜色] [内阴影]``;  

### opacity不透明度  
* 可以调整整个盒子的透明度  
* 值越大，越不透明：0~1之间的值  


## 新增背景属性  
### background-origin原点  
* 背景图片默认起点为padding区域的左上角（没有就是内容区）  
* padding-box（参考padding的顶点-默认的）  
* content-box （参考内容区去平铺-内容区的左上角）  
* border-box（参考边框的左上角起点作为开始）  

### background-clip修剪  
* border-box，border以外的背景不可见（默认）  
* padding-box，超过padding以外的背景不可见  
* content-box，超过内容以外的背景不可见  
* text，前提：文字需要透明的颜色；（这里需要加上前缀：-webkit-），此时背景只呈现在文字上，其他的不会呈现  

### background-size修改背景尺寸  
* 设置宽高  
* 需要注意图片的比例  
* 对于宽高，可以设置px、百分比（参考对应元素的宽高）、contain（包含，容器需要把背景包含进去，会将图片完整呈现在对应元素中，并且需要填满）  
* 最佳方案：cover（尽量完整的展示出背景图，其余会被抛弃）  
* auto默认（展示原图）  

### background-复合属性  
* ``background: 背景颜色 背景url 是否重复 位置 / 尺寸 原点 裁剪方式（最后两个属性可以设置相同值）``  

### 多背景图  
* css3允许我们为一个元素设置多个不同的背景图  
* ``background: url('src') no-repeat x方向 y方向(可以写关键词), ...;``  
* 注意，只能是background，background-image只能设置一张图  
* background: transparent;可以抵掉图片的设置  

## 新增边框属性  
### border-radius边框圆角  
* 设置值为对应边框内切圆的半径  
* border-radius：50%（正方形），此时就可以成为一个纯圆了  
* 还可以设置四个位置的圆角  
* 另外此半径不仅仅设置一个值，还可以设置x y->椭圆，x是x轴方向上的半径，y是y轴方向上的半径  
* 组合写法写椭圆的时候，x方向和y方向需要分开写，且是一组（左上、右上...），中间用/进行分隔：``border-radius: 100px 50px 20px 10px / 50px 20px 10px 5px``  

### 边框外轮廓  
* 盒子发出来的光  
* outline-width：外轮廓的宽度  
* outline-color：外轮廓的颜色  
* outline-style：外轮廓的风格  
	1. nono：无轮廓  
	2. dotted：点  
	3. dashed：虚线  
	4. solid：实线  
	5. double：双线轮廓  
* 上述复合属性：  
	- outline: 50px solid blue;  
* outline-offset：设置外轮廓与边框的距离(不属于复合属性中的子属性)  

## 新增文本属性  
### text-shadow文本阴影  
* 实际上就是对于盒子阴影，将外延值和内阴影给去掉了，其余一致  
* ``text-shadow: x偏移 y偏移 [模糊值] [color]``  
* 应用场景：对于背景比较浅，文字比较浅的地方可以对文本添加阴影：``text-shadow: 0px 0px 15px black;``、或者背景是深色，我们可以做出光晕的效果：``text-shadow: 0px 0px 20px red;``  

### white-space文本换行  
* white-space: pre; 表示对应元素内的文字格式按照原文显示（类似于pre标签呈现的效果）  
* white-space: pre-wrap;再pre的基础上，特别长的不会超出元素范围，会自动换行  
* white-space: pre-line;再上面的基础上，每一句话的左边和右边的多余的空格忽略掉  
* white-space: nowrap;（高频）所有的东西全部弄成一行，强制不换行  

### text-overflow文本溢出  
* 场景：全部内容一行呈现（列表中的每一行），即使很长，使用...进行代替，表示后面还有东西  
* 所以前提不换行：设置文本强制不换行：white-space: nowrap;  
* text-overflow: clip;  超出部分的文字截掉（注意想要生效，需要overflow: hidden;忽略子元素溢出）  
* text-overflow: ellipsis; 超出部分文字用...代替，同样需要hidden进行忽略  

### text-decoration文本修饰  
* css2中：text-decoration的常用值有：none(没有)、underline(下划线)、overline(上划线)、line-through(删除线)...  
* css3中新增一些子属性：  
1. text-decoration-line: overline;  对线设置  
2. text-decoration-style: dashed;  线的样式  
3. text-decoration-color: blue; 线的颜色  
* ``text-decoration: [线] [样式] [颜色];``  css3中对文本修饰升级为了复合属性  

### text-stroke文本描边  
* 只有webkit内核的浏览器可以使用  
1. -webkit-text-stroke-color: red;  直接设置颜色没有效果  
2. -webkit-text-stroke-width: ;  设置宽度  
* 可以成为复合属性  
* 应用场景：文本颜色设置为透明可以制作空心文字效果  


## 新增渐变  
* 渐变，本质上是一个背景图片（代码构建）  
### linear-gradient线性渐变  
* ``background-image: linear-gradient([to right,]red [50px], yellow [100px], green [150px]);``  
	- 颜色阶段：红色、黄色、绿色;，默认从上到下线性渐变颜色  
	- 颜色个数任意即可  
	- to属性可以设置朝哪个方向(渐变方向也可以是右上角(to right top))，颜色顺序为书写属性时从左到右的顺序  
	- 除开使用to关键词进行调整，还能替换为更加精确的值进行调整：20deg，表示20度角（整个渐变的旋转角度）  
	- 颜色后面跟上像素大小的话，表示距离**渐变方向**多少像素，颜色为纯颜色（之前就会存在渐变，如果没有颜色，那么就是绝对纯了）  
### radial-gradient径向渐变  
* ``background-image: radial-gradient([circle,][at right top,]red [50px], yellow [100px], green [150px]);``  
	- 此径向渐变半径默认以其元素的宽和高作为基准  
	- 使用at能够设置圆心位置，关键词  
	- 除了使用at具体关键词，还能at x像素 y像素进行精确控制圆心的位置（参考元素左上角）
	- 添加circle关键词，可以强制将渐变变成圆（非跟着宽和高走的）  
	- 除了关键词，可以添加x方向的半径和y方向上的半径[xpx, ypx]  
	- 颜色后面设置像素距离（到达距离为纯色），表示基于圆心的半径长度，顺序为书写固定的从左到右  
### repeating- -gradient重复渐变  
* repeating重复，建立在前面两种渐变的基础上  
* 重复渐变的前提：**在没有发生渐变的区域（纯颜色区域）**，重新开始渐变（以最后一个颜色没有开始渐变的开始，重新按照设置的顺序进行渐变），这就是重复渐变  
* 径向渐变和线性渐变同理  

### 渐变小案例  
* 利用一个小缝隙填充灰色，利用重复线性渐变做出格子纸的效果：  
```css
{
    background-image: repeating-linear-gradient(transparent 0px, transparent 29px, grav 30px);
    background-clip: content-box;
}
```

## 2D变换  
* 2D坐标，元素的左上角为0,0向右边x+，向下变y+  
### translate位移  
* **transform**:  translate(x, y);  可以调整x、y方向上的位置。（如果只设置一个值，只是设置x轴方向）  
* 类似于相对定位，相对的坐标系就是当前元素所在的坐标  
* 可以单独设置x和y：translateX、translateY  
* 位置可以是百分比，参考的是自身宽度、高度的百分比（相对定位参考的是父元素）  
* 注意：  
	1. 和绝对定位不同的是，此元素进行位移并不脱离文档流（不会影响其他元素）  
	2. 设置水平垂直居中可以利用transform进行2d位移代替margin  
	3. 浏览器针对位移存在优化，即：与定位相比，**浏览器处理位移效率更高**  
	4. 位移对行内元素无效  
```css
{
    position: absolute;
    left: 50%;
    top: 50%;
    transform: translate(-50%, -50%);
}
```

### scale缩放  
* transform: scale(x, y); 可以写一个值，同时代表两个方向   
* 同样可以单独设置x、y方向上的缩放：scaleX()、scaleY()  
* 值不带单位，表示在对应什么方向上进行放大多少倍，并且可以写负数（对转，翻转）  
* 可以利用缩放调整文字的最小大小，比如12px  
* 注意：  
	1. 缩放同样无法应用在行内元素上  

### rotate旋转  
* transform: rotaeZ();(注意，x、y和3d属于3D的旋转变换)、也可以写rotate()默认写一个值就是z轴旋转  
* 值需要给角度值deg，顺时针旋转  
* 同样不能使用在行内元素上  

### skew扭曲  
* 使用很少  
* transform: skew(xdeg, ydeg); 值为角度值，只写一个默认x方向上的扭曲  
* 可以分开设置：skewX、skewY  
* 同样不能使用在行内元素上  

### 多重变换  
* 实际上就是上面几种写在一起的综合写法  
* transform: translate() scale() rotate();
* 需要注意位移参考的是自己的位置(自己元素的左上角)，注意缩放、旋转、扭曲的影响，一般先将旋转放在最后（否则坐标系会发生变化）  

### transform-origin变换原点  
* 实际上，之前变化都是围绕着一个点进行变换的，这个点就是原点  
* transform-origin: xpx y px;(依据于原本的坐标系)  
* px可以设置方位名词：top、left...  
* 也可以设置百分比，参照的是自身的宽度和高度  
* 如果只设置一个值，对于left、right（或者px）那么x轴设置对应，y轴默认50%，top和bottomy轴设置对应，x轴默认50%  
* 变换原点对于位移没有影响，对于缩放存在影响（趋近于原点）  


## 3D变换  
* 默认情况下，网页布局全都是2D空间  
* 想要对一个元素设置3D变换，需要对其父元素开启3D空间  
### 3D空间与景深  
* 开启3D空间：**transform-style: preserver-3d **(默认flat是2D空间)  
* 景深：z=0的平面距离观察者的距离（设置景深可以更好的看到3D的效果，配合设置3D空间进行使用）  
	- **perspective: px**  
	- 设置了景深，存在透视效果-近大远小  
	- 一般情况下：500~1200px比较柔和  
	- 默认值为none（没有透视效果）  
### 透视点的位置  
* 所谓透视点就是观察者  
* 默认透视点的位置在开启3D空间的那个元素的中间位置  
* 在设置3d空间的地方，可以修改透视点的位置：perspective-origin: xpx ypx(基于当前元素的左上角)  
### 3D位移  
* transform: translate3d(x, y, z)（三个值都必须写）  
* 可以分开写，比如: transform: translateZ();  
* 注意与景深距离，等于景深处于同一平面就看不到了  
* 并且z轴不能写%（元素没有厚度）  
### 3D旋转  
* transform: rotate3d(if x, if y,if  z, deg );(前面三个值用0、1表示是否旋转，后面deg写相同的度数)  
* 3d变换相关的旋转：rotateX、rotateY。**x的旋转元素的右边去看是顺时针的，y的旋转是从元素的下边看是顺时针的**  
### 3D缩放  
* 在2D缩放的基础上，增加了Z轴方向上的缩放scaleZ，影响景深（没有厚度，相当于当前景深除以当前的缩放Z）(需要旋转一下可以看到明显的效果)  
* transform: scale3d(x, y, z)  
### 多重变换/变换原点  
* 可以调整变换的原点：transform-origin: left;这里可以把旋转的轴从中间改为了左轴（left top、left bottom都是左轴，其余同理）  
	- 同样的可以设置transform-origin: xpx ypx;
* 多重变换同样是综合属性，也是推荐旋转放在最后即可  
### 背部可见性  
* 因为3D变换可以看到一个元素的背部，可以设置一个属性让背部不可见  
* backface-visibility: hidden;  此时背部不可见（隐藏）

## 过渡  
* 让元素从一个状态，慢慢的变成另外一个状态  
### 基本使用  
* 给对想发生过渡的元素添加属性: transition-property: ; 过渡的属性（注意过渡的必须发生变化）  
	- 比如width、height、background-color、all  
* 设置过渡的时间: transition-duration: ;过渡的持续时间（默认0s）  
	- 单位为：s、ms  
	- 可以分别设置对应变化属性不同的过渡时间  
* 属性能够用数值去表示，都可过渡。如果不能转换成数值，就无法进行过渡  
	- display就不行  
	- 支持过渡的：颜色、长度值、百分比、z-index、opacity、2D3D变换、阴影  

### 高级使用  
* 过渡的延迟  
	- transition-delay: ;设置延迟的时间  
* 过渡类型transition-timing-function  
	1. ease平滑过渡 默认类型，慢-快-慢（柔和）  
	2. linear线性过渡 匀速  
	3. ease-in 慢-快  
	4. ease-out 快-慢  
	5. ease-in-out 慢-快-慢  
	6. step-start 一步到位  
	7. step-end 过渡时间完到达终点  
	8. steps(20, end) 表示在过渡时间内，分成20份进行.(默认end，第一份会等会儿刷新，start会过渡一开始进行刷新)  
	9. cubic-bezier()贝塞尔曲线  
		- S-T曲线，时间距离曲线-切线就是速度  
		- 曲线测试网址：<a href="https://cubic-bezier.com/">贝塞尔曲线</a>  
		- 自定义  

### 过渡的复合属性  
* transition: 过渡时间 过渡属性 过渡延迟 过渡类型;  
	- 注意过渡时间和过渡延迟设置的时间设置顺序，如果只设置了一个时间那么就不存在延迟  

## 动画  
* 给网页设置几个关键帧即可  
### 基本使用  
* 应用动画：animation-name: ;动画名字（自定义）  
	- 配合在css内设置关键帧去设置动画  
* 设置动画持续时间: animation-duration: 3s;(不存在触发条件，刷新网页即可播放)  
* 动画的延迟时间：animation-delay: 0.5s;  
```css

	animation-duration: 3s;
}
/* 定义一组关键帧 */
@keyframes donghua {
    /* 第一帧 */
    from {
        
    }
    /* 最后一帧 */
    to {
        transform: translate(900px);
    }
}
```

* 上面只是简单粗略的定义动画帧的方式，下面存在精细的定义动画帧的方式：  
```css
/* 定义一组关键帧 */
@keyframes donghua2{
    0% {        
    }
    100% {
        transform: translate(900px);
    }
}
```

* 注意form、to和百分比都是可以混合着来的  

### 其他属性  
* 调整动画过渡类型：  
	- animation-timing-function: ; --和过渡可选值完全一致  
* 动画播放的次数：  
	- animation-iteration-count: ;  
	- infinite值可以设置无限循环  
* 动画方向：  
	- animation-direction: ;  
	- 默认值：normal(0->100)  
	- reverse反转(100->0)  
	- alternate往复运动（0->100->0）  
	- alternate-reverse(100->0->100)  
* 动画以外的状态（不发生动画的时候在哪里）：  
	- animation-fill-mode: ;  
	- forwards 表示最后一帧在哪里，最后就保持在哪里  
	- backwards 默认-最后保持到第一帧的状态  
* 动画的播放状态：  
	- animation-play-state: ;  
	- paused 暂停状态  
	- running 运动状态(默认)  

### 动画的复合属性  
* animation: 动画名 持续时间 延迟 动画过渡类型 动画播放次数 动画方向 动画结束状态 [动画化播放状态]  
* 同样的只注意时间顺序即可  

### 过渡和动画的区别  
1. 动画不需要任何的触发条件，过渡必须存在触发条件  
2. 动画可以通过关键帧对整个过程中进行精细的设置

## 多列布局  
* 对于一些应用场景，比如新闻报纸上的排版，除开使用浮动进行横排布局（但是有些局限并且不好处理），还可以使用多列布局进行排布  
* column-count: 列数; 指定列数  
* column-width: ;指定每一列的宽度，自动计算列数  
* columns: 列数 宽度;  
* 调整列边距：column-gap: px;(写0px的话也会存在一定缝隙)  
* 设置列框属性：  
	1. column-rule-width: px; 框宽  
	2. column-rule-style: ; 框样式  
	3. column-rule-color: ; 颜色  
	* 复合属性：column-rule  
* 设置元素横跨很多列（找到需要跨列的元素）：column-span:  
	- none 默认，不跨很多列  
	- all 跨全部列  
* 图片img同样可以插入，width=100%会自动适应当前列的宽度  

## 伸缩盒模型-弹性盒子  
* 09年，w3c提出了新的盒子模型：Flexible Box  
* 它可以轻松的控制：元素分布方式、元素对齐方式、元素视觉顺序......  
* 伸缩盒模型的出现，逐渐演变出一套新的布局方案：flex布局  
	- 传统布局：基于传统盒模型，主要靠：display（转换）+position（定位）+float（浮动）  
* 对于伸缩盒模型，外面大的承装东西的叫做容器，内部叫做伸缩项目  

### 伸缩容器与项目  
* 变成伸缩容器 **display: flex**;  
	- 没有脱离文档流  
	- 伸缩容器的所有的子元素变成了伸缩项目（注意只能是子元素）  
	- 默认项目全部横向排开  
* 另外：**display: inline-flex**也可以将元素变为伸缩容器，但是首先是将其变成了行内块元素（很少使用）    
* 成为了伸缩项目后，无论是什么盒子的元素都变成了块（块状化）  
	- 也能同时成为容器和项目  

### 主轴方向  
* 默认情况下，主轴为x轴方向，从元素的左到右；侧轴为y轴方向从元素的上到下（默认与习惯）  
	- 修改主轴方向 flex-direction: row(默认，从左到右)、row-reverse(从右到左)、column(从上到下)、column-reverse(从下到上)  
	- 伸缩项目沿着主轴排列  

### 主轴换行方式  
* 在主轴方向上排列的项目，默认情况下是都挤占一行，不会出现换行的  
* **flex-wrap**: nowrap(默认不换行)、wrap(换行) 、wrap-reverse(是指从下往上进行换行)   
	- 默认不换行。如果存在换行：在侧轴方向上并不会紧凑在一起，而是将富裕的空间全部利用，会再周围留出相等间距的空隙。当然，如果不富裕就会进行紧凑在一起   

### flex-flow复合属性  
* 用此属性进行同时指定主轴方向和主轴换行方式  
* flex-flow: 主轴方向 主轴换行方式;  
* 最好分开写  

### 主轴的对齐方式  
* **justify-content:** flex-start(默认，轴的开始对齐)、flex-end(轴的结束位置对齐)、center(轴的中间位置对齐)、space-around(项目与项目之间的大小为2倍的大小，项目与边缘的大小为1倍的大小)、space-between(项目均匀分布在一行中，项目与项目之间的距离相等，距离边缘没有距离)、space-evenly(项目均匀的分布在一行中)  
	- 注意放置项目的顺序任然遵循主轴的方向  
	- 上面之间的距离均是针对于每一行，而不是整个整体  

### 侧轴对齐方式  
#### 一行情况  
* **align-items:** flex-start(侧轴的起始位置)、flex-end(侧轴的结束位置)、center(侧轴的中间位置)、baseline(基线对齐-x对齐)、stretch(仅在所有的伸缩项目没有设置高度的时候生效，充满整个容器（拉伸），默认值)  

#### 多行情况  
* 每一行的高度以最高块项目为准  
* **align-content:**  flex-start(侧轴的起始位置)、flex-end(侧轴的结束位置)、center(侧轴的中间位置)、space-around(侧轴上行与行之间距离为2倍的大小，行与边缘距离为1倍的大小)、space-between(行与行之间的距离相等，与边缘之间没有距离)、space-evenly(行与行与边缘之间的距离绝对的平分)、stretch(仅在所有的伸缩项目没有设置高度的时候生效，充满整个容器，默认值)

### 元素的水平垂直居中  
* 方案1：只需要设置flex布局主轴方向上对齐方式、侧轴方向上对齐方式均为center即可  
```css
{
    justify-content: center;
    align-items: center;
}
```

* 方案2：对开启flex布局的子元素（项目），设置一个margin: auto;即可  

### 项目在主轴的基准长度  
* flex-basis: px;  
* 设置伸缩项目在主轴上的基准长度，如果主轴是横向的，宽失效，若是纵向的，高失效  
* 默认值为auto（即无效，默认宽和高，浏览器会根据此属性进行计算宽度）  

### 伸缩性  
#### 伸  
* 父元素的空间存在富余  
* 给需要伸的项目增加属性：**flex-grow: ** 值;   
	- 值为总需要伸缩空间所占的份数，即剩余空间（需要伸占具的空间）``* 值/总份数``  
		- 比如三个项目为：1、2、3；那么它们分别瓜分：1/6、2/6、3/6  
	- flex-grow: 1;表示在对于剩下的空间，全部项目均分，添加伸宽度   
	- 默认0，不会进行拉伸  
#### 缩  
* 父元素的空间不够了  
* 给需要缩的项目增加属性：**flex-shrink: ** 值;  
	- 默认值为1.(根据权重，谁宽度大分担的越多)   
	- 计算收缩比公式：  
		1. 分母：每个项目的宽``*flex-shrink``的值进行累加  
		2. 收缩比: ``当前项目的宽*flex-shrink``/ 分母  
	- ``最后对应的项目宽度=宽度 - 项目收缩比*收缩的总宽度``  
* 极限收缩：保持元素内内容的体现  

### flex复合属性  
* flex: 拉伸 压缩 基准长度;  
	- 对于flex: 1 1 auto;可以简写为flex: auto;  
	- 对于flex: 1 1 0;（可以压缩拉伸，每个项目均分长度）可以简写为：flex: 1;(使用这些最多)  
	- 对于flex: 0 0 auto;(不可以压缩拉伸) 可以简写为：flex: none;  
	- 对于flex: 0 1 auto;(不可以拉伸，可以压缩-默认值) 可简写为：flex: 0 auto;  

### 项目排序与单独对齐  
* 对项目设置属性：order,默认值为0.会按照html的先后顺序进行展示项目元素  
	- 值越小，视觉顺序越前  
* 对于项目设置属性：align-sleft, 此时可以单独调整对应项目在侧轴方向上的对齐（用的不多）

### 媒体查询  
* ``@media``  
1. 媒体类型  
    - print表示媒体是打印机  
    - screen表示媒体是屏幕  
    - all表示全部  
* 用上述在css中识别媒体，然后在大括号内设置css样式即可  
* 需要注意优先级并没提高  
```css
	@media print {
        /* css */
	}
```

2. 媒体特性  
	- (width:800px) 检测到视口的宽度为800px时，应用如下样式  
	- (max-width:700px)检测到视口的宽度小于等于700px，应用如下样式  
	- (min-width:900px)检测到视口的宽度大于等于700px，应用如下样式  
	- 存在height同样，但是一般不用  
	- (device-width:1920px)检测当前设备的屏幕宽度  
	- (orientation: )检测视口的旋转方向：portrait-纵向（高大于宽）、landscape-横向(宽大于高)  
```css
	@media (width:800px) {
        /* css */
	}
```
3. 运算符  
	* and表示多个条件同时成立() and ()-且运算符  
	* or,表示多个条件均可成立(), ()-或运算符  
	* not表示否定此条件 not ()-否定运算符  
	* only表示肯定此条件 only ()-肯定运算符(处理IE的兼容问题)  
### 常用阈值  
* 下面的响应式阈值仅作为参考  
* ``<768px`` 超小屏幕  
* ``< 992px`` 中等屏幕  
* ``< 1200px`` 大屏幕  
* ``> 1200px`` 超大屏幕  
* 实际使用过程中分为如下两种：  
	1. 直接引入四种css，并且在那里进行判断媒体特性  
	2. 媒体特性在link标签中判断：增加属性：media="条件"即可  

## BFC  
* 什么是bfc？  
	- 块格式化上下文，是web页面可视渲染css的一部分，是块盒子的布局过程中发生的区域，也是浮动元素与其他元素交互的区域  
	- 块级格式上下文，可以理解为元素的一个**特异功能**  
	- 该特异功能在默认情况下是关闭的，当元素满足某些条件后，该特异功能被激活  
	- 激活了特异功能，即改元素创建了BFC  
* 开启了bfc解决的问题：  
	1. 子元素不会产生margin塌陷问题  
	2. 自己不会被其他浮动元素所覆盖  
	3. 子元素浮动，元素的自身高度也不会塌陷  
* 如何开启？  
	1. 根元素  
	2. 浮动元素  
	3. 绝对定位、固定定位元素  
	4. 行内块元素  
	5. 表格单元格：
	6. overflow的值不为visible的元素  
	7. 伸缩项目  
	8. 多列容器  
	9. column-span为all的元素(多列布局里面需要横跨列的属性)  
	10. display值设置为flow-root（影响最低）
